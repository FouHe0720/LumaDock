# LumaDock 0.9.0

## Dock 与桌面

拖到 Dock 时，插入标记会指出落点。支持放在第一项之前、任意两个应用之间和最后一项之后；已经固定的应用会移动到新位置，不重复添加。横向与纵向 Dock 使用相同操作。

将 Dock 应用拖到 Windows 桌面，可创建真实快捷方式。普通程序保留启动参数和工作目录，打包应用使用系统 Shell 标识。原程序、已有桌面快捷方式和 Dock 固定项都保留；需要取消固定时，在 Dock 中右键移除。拖拽过程中按 Esc 取消。

## 应用整理

开始菜单、桌面与系统应用列表按启动身份合并。浏览器仅启动来源统计不同的入口合并；独立配置、网页、不同参数和卸载工具仍保留。旧固定 ID 自动映射到保留项，自选图标、桌面关联与虚拟分类继续使用。

分类补充常见中文应用、开发工具和 Windows 系统组件，增加“创作设计”“社交通讯”。手动调整的分组带有独立标记，重新扫描不覆盖。旧版本没有保存这个标记：与旧自动值相同的分类会迁移一次，已识别的自定义分组保留。

## 字体与外观

“字体与文字”统一控制应用名称、侧栏、分类、标题和操作文字的字体与粗细。系统跟随读取 Windows 当前生效的图标字体；独立模式可以选择字体、加粗和斜体。界面保留字号层级，大号应用名称自动调整网格。

文字颜色提供自动、预设色与自定义 `#RRGGBB`。高对比度模式优先系统文字颜色。以上选项只作用于 LumaDock，不改变 Windows 全局字体。

更新 L 标识，统一窗口、Dock 和托盘入口；减少侧栏未选中项的描边，让选中状态和内容层级更清楚。

## 资源与验证

切换已识别的窗口时复用窗口身份索引，减少重复读取进程和 Shell 属性；图标停稳、拖拽结束和窗口关闭后停止相应计时器。修正搜索框聚焦时仍运行的光标动画时钟，保留原生输入框、系统插入点与选区。动态壁纸继续使用系统实时合成。

实际结果、环境与限制分别见 [验证范围](validation.md) 和 [性能记录](performance.md)。便携版完整解压即可运行，不需要额外字体工具、主题软件、SDK 或 IDE。
