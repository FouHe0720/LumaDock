# 性能记录

性能结果按版本和二进制哈希区分。短时采样用于观察资源占用，不代替连续操作、全屏游戏、睡眠唤醒或长期驻留验证。

## 测量方法

在 Windows 交互桌面使用自包含 Release 包，分别测量 Dock 空闲和应用库前台。每轮使用独立配置，先完成扫描和缓存预热，再按固定间隔记录进程 CPU、工作集、私有提交、私有工作集、句柄及前台状态。

```powershell
./scripts/measure-performance.ps1 -Seconds 60 -WarmupSeconds 20
./scripts/measure-performance.ps1 -Seconds 60 -WarmupSeconds 25 -ShowLaunchpad
```

前台轮需激活应用库，并核对 CSV 的 `isForeground`。测量期间不悬停 Dock，不同时运行 UI 压力测试；完成界面确认后，结束自动化界面检查会话，再进行静置采样。持续遍历控件树会引入额外开销，不能混入普通空闲基线。指针静止时的结果不代表持续移动和拖动时的峰值。

从 0.9 起，CSV 同时记录 `hasNativeCaret`：仅对被测应用的前台 GUI 线程读取系统插入点，不读取输入内容。它用于区分普通前台展示与输入框聚焦后的空闲状态；最终前台轮还需确认搜索框聚焦。

| 指标 | 含义 |
| --- | --- |
| 全机 CPU | 进程 CPU 增量 / 时间增量 / 逻辑处理器数 |
| 单核 CPU | 不除以逻辑处理器数，100% 代表一个逻辑核心持续忙碌 |
| 私有工作集 | 当前驻留在物理内存中的私有页 |
| 私有提交 | 进程提交的私有内存，与工作集不同 |
| 总工作集 | 包含共享页，不能当作私有工作集 |
| 首帧 | 应用内计时，不包含下载、解压或完整进程创建时间 |

报告位于 `artifacts/performance/<时间戳>/`，包括 `summary.json`、`samples.csv`、`binary-manifest.json`。分发报告中的机器路径使用相对名称，数值和二进制哈希不作变更。

内存表中的 MB 按 1024 × 1024 字节换算；CPU 为进程统计，不包含外部检查工具自身的 CPU。

### 检查工具的额外负载

排查阶段，前台窗口持续收到外部控件检查请求，同一份二进制的 60 秒轮记录为全机 CPU 1.19334%。对照诊断在没有活跃动画、布局更新或业务刷新时仍观察到这些请求，历史版也出现类似开销。结束开发用界面检查会话后，以上正式前台轮降至 0.00489%，搜索焦点与原生插入点仍有效；没有停止用户程序，也没有屏蔽可访问性。

受干扰轮不与普通空闲数据合并。其实际数值、短时对照与消息计数保留在 `artifacts/tests/inspection-comparison-0.9-results.json`；它们属于排查证据，不是相对性能基准。屏幕阅读器或其他持续检查控件的软件可能增加开销，尚未完成专项量化。

### 光学计算

薄横条背景复用每行相同的光学参数与采样坐标。与 0.6.0 同进程编译比较，12 对预热后交替执行 30 轮，记录中位耗时。输出仍是原分辨率，8 组固定与 160 组随机输入逐字节相同。

| 合成输入与输出 | 0.6.0 基线 | 0.7.0 | 热态每次托管分配 |
| --- | ---: | ---: | ---: |
| 720×64，清晰度 .65，1:1 源映射 | 6.184 ms | 3.042 ms | 两者均 184,384 字节 |
| 799×79，清晰度 .3，1:1 源映射 | 12.220 ms | 6.243 ms | 两者均 252,552 字节 |
| 800×450，清晰度 .65，1:1 源映射 | 27.073 ms | 25.841 ms | 详见原始报告 |

报告：`artifacts/tests/lens-optimization-0.7.json`。这些是 CPU 图像算法夹具数据，不含后方区域捕获、WPF 合成、GPU 或持续鼠标输入。薄横条约 49–51% 的耗时下降不能推广为整机 CPU 减半；大面板的小幅差异也不作通用收益承诺。竖向 Dock 继续使用通用光学路径。

静态背景另有自适应采样退避，连续不变时由 120 ms 逐步延至 1000 ms，另加请求合并节流；检测到变化恢复。它减少重复工作，不降低输出分辨率，但新变化在退避状态下可能多等待约一秒。图标插值在运动收敛后停止，与背景更新独立。

## 解释与边界

私有工作集低于 120 MB 是优化目标；共享页、缓存、显卡驱动、显示器数量、缩放和可见窗口内容都会影响结果。当前动态透景使用系统合成，静态折射按窗口事件取样和计算；流光使用有限时长的交互动画，静止后停止。

单轮数据不能说明冷/热启动分布，也不能把版本差异归因于某一项修改。资源短期下降不证明没有泄漏。尚未提供 GPU、持续指针移动、独占全屏或过夜运行的量化结果。兼容性与验证范围见 [验证记录](validation.md)。
