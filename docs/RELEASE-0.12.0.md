# LumaDock 0.12.0

**应用与系统控制，在一条 Dock 上。**

[使用指南](USER-GUIDE.md) · [Windows 集成](WINDOWS-INTEGRATION.md) · [性能记录](performance.md)

## Dock 系统区

Dock 尾部加入后台应用、中英文模式、键盘布局、网络／音量／电源组合区，以及时间和完整日期。入口各有明确的用途，点击展开对应内容。

- **后台应用箭头**连接 Windows 的真实后台托盘，图标和应用菜单仍由系统与各程序提供。
- **中／英**单击请求切换当前工作窗口的输入模式；旁边的**键盘布局**独立选择已安装的输入法或布局。
- **快捷控制**采用玻璃面板，提供默认播放设备音量、静音和支持的内置屏幕亮度滑块。网络、蓝牙及完整快捷设置打开 Windows 对应入口。
- **时间与日期**打开月历，可翻月、回到今天，并进入通知或日期时间设置。
- 面板还提供开始、搜索、任务视图、显示桌面、通知与任务管理器入口。

“偏好设置 → 系统状态区”可以分别修改图标大小、文字大小和文字／字形粗细，也可关闭系统区或正在运行的应用展示。这些偏好只对 LumaDock 生效。

## 运行应用与窗口菜单

未固定但拥有真实可见窗口的应用临时出现在 Dock，关闭后移除。固定项与运行项尽可能按可验证身份合并；窗口菜单支持选择、最小化和请求正常关闭。共用宿主、不同浏览器配置和不同 AUMID 不靠名称猜测合并。

运行分组不自动改变应用库、固定排列或栏目。关闭窗口使用普通关闭请求，目标程序可以先保存内容或拒绝关闭。

## 应用库／桌面集

恢复两个清晰入口：应用库展示全部已发现与手动添加的应用；桌面集显示当前仍存在的桌面快捷方式对应应用。两页共用整理结果，支持搜索、启动、固定、图标选择与用户自建栏目。

同一应用的不同启动方式收在一张卡片的右键菜单中，原始路径、参数和工作目录保留。初次使用仍没有强制自动分类，现有自建栏目与固定顺序继续保留。

## 玻璃与驻留

新增弹窗沿用原生合成的玻璃背景、圆角与强调色。时钟按分钟边界更新，Dock 隐藏后暂停；网络、电源、窗口、输入与音频按事件更新，亮度只在打开面板或用户操作时查询。图标与倒影复用已有缓存，静止时停止悬停和反光动画。

Dock 延续普通窗口层级，其他应用始终可以位于其上方。LumaDock 不会自动隐藏 Windows 任务栏，也不改变系统桌面布局。

## 使用边界

- 后台托盘沿用 Windows 自己的弹窗外观；Explorer 入口不可用、策略禁用或任务栏被其他工具完全移除时，可能无法展开。
- 第三方输入法未提供可读取的模式状态时，模式按钮禁用；布局列表仍来自实际安装的 profile。系统前台与跨权限限制可能拒绝切换，会显示失败。
- 自绘亮度滑块控制支持 WMI 接口的内置屏幕；外置显示器可从显示设置调整。没有可用播放端点时音量控件禁用。
- WLAN、蓝牙、飞行模式等完整开关由 Windows 的真实设置界面提供；LumaDock 不伪造切换状态。
- Windows 10、混合 DPI 双屏、提权程序、独占全屏与长期驻留仍需专项验证。具体结果见[验证记录](validation.md)，实际采样见[性能记录](performance.md)。

便携版自带 .NET Desktop Runtime，完整解压即可运行。升级前可从“偏好设置 → 数据”导出配置；本版继续使用配置格式 2，保留原有固定项、自选图标与自建栏目。
