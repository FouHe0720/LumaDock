# LumaDock 0.10.2

这次小更新只调整 Dock 的窗口层级，使用其他软件时更安静。

打开或切换到应用后，应用保持在 Dock 上方。刷新应用列表、移动 Dock 或改变显示器时，也会保留普通窗口层级，不会重新把 Dock 顶到工作窗口前面。

需要使用 Dock 时，返回桌面即可；**Ctrl + Alt + Space** 继续打开应用列表。固定应用、拖动排序、自建栏目、图标倒影、鲜艳度和玻璃外观均延续 0.10.1，原有设置继续保存。

完整解压 **LumaDock-0.10.2-win-x64.zip**，运行 **LumaDock.exe**。便携包包含 .NET Desktop Runtime，无需另装 SDK 或 IDE。配置格式继续使用版本 2，升级前可在偏好设置中导出备份。

本版 Release 解决方案 19 个项目构建通过，0 警告、0 错误；247 项组件与 WPF 检查、100 次窗口开合和搜索通过。Dock 的 89 项检查包含自有普通窗口的实际前台 Z 序，覆盖四边重定位、刷新、重建和清除残留原生置顶状态。

同一份发布程序保留了一轮含已创建主界面的后台静置记录，采样期间均未处于前台；该记录不作为纯 Dock 基线。完整数值和运行条件见 [性能记录](performance.md)。

当前为预发布版本。具体测试范围和实际资源记录见 [验证记录](validation.md) 与 [性能记录](performance.md)，完整操作见 [使用指南](USER-GUIDE.md)。
