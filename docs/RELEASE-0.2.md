# LumaDock 0.2.0

Windows x64 便携预发布版。解压整个 `LumaDock-0.2.0-win-x64.zip` 后运行 `LumaDock.exe`；包含 .NET Desktop Runtime，无需安装 IDE 或 SDK。

## 这一版的变化

- Windows 11 22621 及以上使用 DWM 原生 Desktop Acrylic。浅色和深色共用统一间距、细边框与高光，Dock、应用窗口及分类弹窗保持一致。
- Windows 10、应用省电模式、高对比度、远程会话或系统关闭透明效果时回退到不透明背景；不会代用户更改 Windows 透明设置。
- 新增原创应用图标和桌面快捷方式脚本。重复打开快捷方式会请求显示已经运行的应用窗口，避免重复驻留。
- 导航和设置改为简短的操作名称，去除宣传文案；应用图标来自真实 Windows Shell 资源。
- 修正管理窗口最大化时的工作区尺寸，避开任务栏。
- 将开合动画限制在内容层，保持原生窗口非分层；减少搜索框光标的重复渲染。
- 新增实际进程的激活测试和真实 HWND 的玻璃属性测试。

## 开始使用

1. 双击本机桌面的 **LumaDock**，或运行发行目录的 `LumaDock.exe`。
2. 用 Dock 左端图标或 **Ctrl+Alt+Space** 打开应用；快捷键被占用时使用托盘菜单。
3. 搜索后点击应用启动。右键可固定到 Dock、移入分组或隐藏管理记录；“添加应用”可选择现有程序或快捷方式。
4. 在“设置”调整主题、Dock 尺寸、位置、透明度和显示器。修改自动保存。
5. 使用托盘或 Dock 菜单的“退出 LumaDock”结束常驻。默认关闭管理窗口会继续驻留托盘。

桌面快捷方式指向 `D:\LumaDock\artifacts\publish\LumaDock.exe`。请保留此发布目录；若要移动到别处，从源码根目录运行 `scripts/create-shortcut.ps1`，用 `-Executable` 指定新的可执行文件、`-Destination` 指定快捷方式位置。发行包不会自行写入开机启动或更改桌面图标显示。

本机实际通过桌面快捷方式打开两次，均显示同一个驻留进程的窗口；最终自包含包的原生玻璃状态同时核对通过，记录在 `artifacts/tests/shortcut-results.json`。

## 验证与限制

本机 Windows 11 x64 已有 19 项 Core/Storage、5 项 Windows Shell、6 项单实例激活、4 项原生背景测试，以及 100 次 WPF 显示/搜索/导航/隐藏、3 次窗口重建和关闭动画期间重新显示的通过记录。查看 [验证记录](validation.md) 了解对应证据及覆盖范围。

最终 0.2 二进制的 Dock 驻留测量 180 秒，平均全机 CPU 0.0426%、私有工作集峰值 50.4 MB；启动台打开但非前台测量 120 秒，为 0.00477% / 63.1 MB，首帧约 317 ms。非前台结果不能代表持续聚焦搜索框；源码开发探针的两轮聚焦测量为单核 2.45% / 1.25%，不是最终发布包基线。完整哈希和原始数据见 [性能记录](performance.md)。未提供过夜、Windows 10、真实混合 DPI 双屏和独占全屏游戏的完整验收结果。

当前无代码签名、安装器、自动更新或桌面时钟。应用分组为单层虚拟分组，不移动真实文件；删除管理记录不会卸载应用。受保护或跨权限窗口可能无法可靠匹配/切换。

依赖安装、开机启动、正常退出、卸载及桌面恢复方法见 [README](../README.md)。本机数据保存在 `%LOCALAPPDATA%\LumaDock`，不会主动上传。
