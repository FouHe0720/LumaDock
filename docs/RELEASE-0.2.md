# LumaDock 0.2.0

历史预发布版本。以下记录描述 0.2.0 的行为与验证，不代表后续版本的资源保证。当前安装和使用方法见 [使用指南](USER-GUIDE.md)。

## 变化

- 接入 Windows 11 DWM Desktop Acrylic，统一深浅色、间距、细边缘和悬停反馈。
- 为不支持原生材质的环境保留不透明回退。
- 新增应用图标与快捷方式创建脚本，重复启动请求唤起既有实例。
- 修正最大化工作区边界，减少内容过渡和搜索光标的重复渲染。
- 增加实际进程激活与原生窗口属性检查。

便携包包含 .NET Desktop Runtime，完整解压后运行 `LumaDock.exe`。当版导航为“应用、桌面、设置、关于”；新版本导航与完整教程以使用指南为准。

## 验证记录

Windows 11 x64 环境中取得以下结果：

| 检查 | 结果 |
| --- | --- |
| Core / Storage | 19/19 |
| Windows Shell | 5/5 |
| 单实例激活 | 6/6 |
| 原生背景 | 4/4 |
| WPF 生命周期 | 100 次循环、3 次重建和关闭途中重新显示通过 |
| 快捷方式 | 连续启动保持同一驻留进程，窗口可见 |

最终二进制 Dock 空闲测量 180 秒，平均全机 CPU 0.0426%，私有工作集峰值 50.4 MB。管理窗口打开但非前台测量 120 秒，为 0.00477% / 63.1 MB，首帧约 317 ms。非前台结果不代表持续输入或操作时的开销。

完整哈希、原始记录及早期探针区别见 [性能记录](performance.md)。Windows 10、真实混合 DPI 双屏、独占全屏游戏与过夜驻留未完成专项验收。

分组为单层虚拟管理，不移动原文件；隐藏记录不会卸载软件。开机启动与桌面图标显示由用户主动确认。没有代码签名、安装器、自动更新或桌面时钟。
