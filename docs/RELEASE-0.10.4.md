# LumaDock 0.10.4

**桌面上的文件，也在桌面集里。**

[使用指南](USER-GUIDE.md) · [性能记录](performance.md) · [验证范围](validation.md)

## 真实桌面内容

桌面集改为独立读取当前用户与公共桌面的顶层内容。文件夹、文档、图片和快捷方式一起显示，图标由 Windows Shell 提供。桌面位置跟随系统设置，不依赖固定的盘符或用户目录。

按实际路径去重，同一路径只显示一次；同名但位于不同桌面目录中的项目分别保留。隐藏、系统项目和 `desktop.ini` 不显示，不递归扫描文件夹内容。应用库继续展示软件启动入口，普通文件不会混入应用清单。

## 新建、打开与整理

- 双击文件夹交给资源管理器，双击文件交给默认关联程序，快捷方式保留原有目标与参数。
- 空白处右键可以新建文件夹或 `.txt` 文本文档，实际保存到当前用户桌面。已有同名项目时自动编号，不覆盖原件。
- 选中项目后通过右键或 F2 重命名实际文件；发生命名冲突时提示，原有目标保留。
- 可以复制项目、复制路径，并将剪贴板中的普通文件复制到桌面。粘贴始终保留原文件，不执行移动。
- 按 F5 或点击刷新重新读取；“打开桌面”保留资源管理器的完整文件操作入口。
- 桌面程序与快捷方式可继续加入应用库或固定到 Dock。

新建、重命名和粘贴会改变真实桌面的内容。文件夹复制、其他新建模板、删除与完整的 Shell 扩展菜单仍交给资源管理器。“回收站”“此电脑”等虚拟系统项目不在真实文件清单中。

## 按需同步

桌面集可见时监听目录事件，合并短时间内的连续变更再刷新。离开桌面集或隐藏窗口后停止监听；重新进入再读取，不持续轮询。图标沿用异步 STA 加载与有界缓存，普通文件和文件夹均使用真实系统图标；文件夹内容变化不会反复使相同图标失效。

延续 0.10.3 的三排应用布局、清楚的运行标记、快速启动提示、悬停放大与倒影。Dock 使用普通窗口层级，其他工作窗口保持在其上方。固定项、自建栏目、自选图标与外观设置继续保留。

本版使用配置格式 2。便携包自带 .NET Desktop Runtime，完整解压后双击 `LumaDock.exe`，无需另装 SDK 或 IDE。新功能的实际验证与资源采样分别记录在[验证范围](validation.md)和[性能记录](performance.md)；旧版本的性能数字保留其版本与测试条件。

## 验证与资源

Windows Release 解决方案 22 个项目构建通过，0 警告、0 错误。194 项组件与 WPF 检查、14 组导入检查、100 轮窗口生命周期通过；实际用鼠标打开新建菜单、填写名称后，文件夹成功写入隔离桌面并出现在视图中。

同一最终程序的 Windows 11 短时实测中，Dock 后台平均全机 CPU 为 0.00164%，私有工作集峰值 60.844 MB；已预热桌面集前台的私有工作集峰值为 67.496 MB，30 秒采样未记录到 CPU 计时增量。该零值不表示绝对零开销，短测也不代替长期驻留或持续操作验收。测试固定 2 个应用、倒影 90%、底座浓度 4%，桌面集读取 48 个真实项目。完整条件、二进制哈希与验收客户端连接时的诊断轮保留在性能记录中。
