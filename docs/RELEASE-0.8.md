# LumaDock 0.8.0

动态透景与图标更新。Windows x64 便携预发布版；完整解压后运行 `LumaDock.exe`，无需另装 .NET 或 IDE。

## 动态透景

默认动态模式改由 Windows 合成后方画面，移除覆盖在上面的低频背景快照。管理窗口默认使用清透风格，保留动态壁纸的细节；Dock 使用真实半透明底座，轮廓、边缘反光和图标放大继续保留。

在“偏好设置 → 材质”保持“动态透景”开启，再选择“清透”或“磨砂”。清透模式新增“窗口浓度”，范围 25–90%，默认 65%，调整管理窗口底色并自动保存；Dock 透明度单独设置。

需要曲边折射时，可关闭动态透景，选择按窗口事件更新的静态背景，并调整“静态折射清晰度”。两种模式各有用途；动态模式不执行实时曲边像素折射，系统合成也没有固定帧率或零延迟保证。

清透路径已在当前 Windows 11 验证环境测试，Windows 10 与其他硬件仍需专项覆盖。省电、高对比度、系统透明效果关闭或不支持原生合成的环境使用不透明回退，不会把一张停住的旧图当作动态透景继续显示。用户也可手动选择磨砂。具体条件见 [材质说明](WINDOW-BACKDROP.md)。

## 图标

修正 Windows Shell 图像提取标志，明确请求图标资源。应用库按当前 DPI 请求合适的像素尺寸，切换缩放后重新加载可见图标；保留快捷方式自定义资源、图像透明度和传统图标掩码。

图标缓存识别文件版本，合并重复请求，失败后可重试。在同一路径替换图标文件后，点击刷新可重新读取。

应用库、桌面集和 Dock 增加“更换图标…”与“恢复原图标”。可以选择本地 `.ico`、`.png`、`.jpg`、`.jpeg`、`.exe`、`.dll` 或 `.lnk`，使用图片或文件中的真实图标资源。选择结果自动保存并共用，不修改原程序或桌面快捷方式。

原始图标自带的边框、底色和留白会保留。更换文件不可用时尝试系统来源；配置只记录路径，不复制文件。对外分享导出的配置前，请检查路径中的私人信息。

## 升级与使用

保留原有应用整理、Dock 排列、名称字体与配色。现有配置中的“动态透景”选择继续生效；关闭状态使用静态模式，如需动画壁纸跟随，请将它开启。
