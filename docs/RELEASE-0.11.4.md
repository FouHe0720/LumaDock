## 修复任务栏重叠后的拖动

此前 Dock 可以保存任务栏区域的位置，但放下后，鼠标可能被上方的任务栏接收，无法再次抓住底座。

本版补上重叠区的输入处理。返回桌面时，实际进入任务栏区域的玻璃底座会保持可操作；从左端握柄继续移动、右端握柄继续缩放。竖向摆放时，对应上端和下端。

切换到工作窗口，包括 LumaDock 自己的主界面时，Dock 会撤回临时提升，恢复普通层级，让工作窗口保持在前。Windows 任务栏的显示和设置保持原样。

## 拖动与点击，各按原来的用途

点击握柄或底座空白处开始操作时，Dock 会激活以取得完整的鼠标捕获。应用图标点击仍用于启动或切换已识别窗口，不因点击本身主动夺取键盘焦点。

16–160 DIP 连续缩放、两端各 32 DIP 操作空位、图标排序、悬停和倒影继续保留。松手保存，Esc 取消；原有大小、位置、固定项与外观偏好保留。

层级由前台窗口事件直接更新，不增加常驻轮询。无法建立观察器时保留普通层级；需要找回底座，可按 **Ctrl + Alt + Space**，进入 **偏好设置 → Dock → 恢复位置**，或从托盘菜单重启 Dock。

## 下载与记录

下载 **LumaDock-0.11.4-win-x64.zip**，完整解压后双击 **LumaDock.exe**。便携包自带 .NET Desktop Runtime，无需另装 SDK 或 IDE。升级前可导出配置备份，退出旧进程后替换程序文件，原有数据目录保留。

本版的任务栏命中、前台切换、拖动与资源结果按最终 Windows 程序单独记录。旧版数据保留在历史段落中，当前检查范围与未覆盖环境见[验证范围](validation.md)和[性能记录](performance.md)。
