# LumaDock 0.3.0

历史预发布版本。当前功能与操作路径见 [使用指南](USER-GUIDE.md)。

## 名称跟随系统字体

应用名称默认读取 Windows 图标标题字体，包括家族、字号、粗细、斜体及装饰线。Dock 提示同步家族、字号、粗细和斜体，导航与设置说明保持界面字体。

名称变大时增加两行文字的空间，并自动降低网格列数。关闭系统跟随后可独立调节名称字号与加粗；范围为 10–40 DIP，界面显示 7.5–30 磅。系统字体读取只查询当前值，不修改 Windows 全局字体。

## 边缘与反馈

增加静态内外细边缘、顶部柔和反光与下缘暗部，降低表面遮盖。应用卡片采用短时悬停反馈，按动画和省电设置减少效果，边缘没有持续帧循环。

当版使用 DWM 原生 Acrylic，尚未引入后方区域取样与像素折射。原生材质不支持时保留更简单的背景。

## 验证记录

Windows 11 x64、.NET 10.0.14 中取得以下结果：

| 检查 | 结果 |
| --- | --- |
| Core / Storage | 22/22 |
| 自适应网格 | 7/7 |
| 系统字体只读集成 | 5/5 |
| 实际 WPF 字体与布局 | 6/6，含系统值、28/40 DIP、桌面名称和字体恢复 |
| WPF 生命周期 | 100 次循环、3 次重建和关闭途中重新显示通过 |
| 原生背景 / 单实例激活 | 4/4、6/6 |

字体测试使用隔离的应用配置，没有改写系统字体。该版本验证的是系统值读取和实际 WPF 布局，不代表系统字体变更后的完整端到端验收。

0.3 未取得最终视觉、正常桌面空闲 CPU、私有工作集或管理窗口延迟基线。其他版本的数字不能替代本版结果。验证证据与覆盖范围见 [验证记录](validation.md) 和 [性能记录](performance.md)。

Windows 10、真实混合 DPI 双屏、独占全屏游戏与过夜驻留仍待专项验证。当版不提供代码签名、安装器、自动更新或桌面时钟。
