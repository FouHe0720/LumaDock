# LumaDock 0.4.0

历史预发布版本。0.4 增加后方画面的边缘折射与内部柔化；当前使用方式见 [使用指南](USER-GUIDE.md)。

## 背景光学层

窗口和 Dock 取样后方有限区域，沿圆角改变图像采样位置，产生曲边位移。内部柔化细节，并保留文字所需的明暗底色。区域来源不可用时，尝试可读静态壁纸，再按条件使用系统背景。

| 选项 | 默认值 | 用途 |
| --- | --- | --- |
| 液态玻璃 | 开启 | 启用折射和柔化 |
| 动态透景 | 开启 | 活跃管理窗口或悬停 Dock 限频更新后方画面 |
| 玻璃清晰度 | 65% | 低值柔和，高值保留细节 |

空闲 Dock、隐藏和不活跃窗口停止持续透景；关闭动态透景后保留事件触发的更新。应用内省电模式关闭自定义折射。背景像素在本地内存处理，普通运行不写背景截图、不上传。

动态区域采样需要 Windows 10 build 19041 及以上与可用桌面合成。采样只临时排除自身窗口，结束后恢复；受保护内容不保证可取得。原生磨砂与自定义折射采用独立回退条件，详见 [窗口材质](WINDOW-BACKDROP.md)。

## 历史短测

Windows 11 x64、16 个逻辑处理器，同一份自包含 Release 二进制：

| 状态 | 预热 / 测量 | 平均全机 CPU | 私有工作集峰值 |
| --- | --- | ---: | ---: |
| Dock 空闲，非前台 | 20 / 60 秒 | 0.02251% | 55.281 MB |
| 管理窗口前台，动态透景开启 | 25 / 60 秒 | 0.9445417% | 90.270 MB |

管理窗口首帧约 342.8 ms，前台 CPU 单核口径为 15.1128%；私有提交峰值 152.492 MB、总工作集峰值 232.777 MB，与私有工作集不同。100 次窗口循环后保留托管堆增加 7,147,168 字节，需要更长观察，不能据短测证明没有泄漏。

完整哈希、原始 CSV、候选版本和诊断边界见 [性能记录](performance.md) 与 [验证记录](validation.md)。Windows 10、真实混合 DPI 双屏、独占游戏、持续动态负载和过夜驻留未完成专项验收，没有 GPU 或 60 fps 性能结论。
