# LumaDock 0.4.0

Windows x64 便携预发布版。解压整个 `LumaDock-0.4.0-win-x64.zip` 后运行 `LumaDock.exe`。本机桌面快捷方式继续指向 `D:\LumaDock\artifacts\publish\LumaDock.exe`；发行包包含 .NET Desktop Runtime，无需安装 IDE 或 SDK。

## 后方画面的折射与柔化

0.4 会取样窗口或 Dock 后方的真实画面，沿圆角边缘改变取样位置，让背景线条在边缘附近产生弯曲。内部会按清晰度柔化细节，并保留文字所需的明暗底色。当前已经在本机运行中取得实际后方画面，管理窗口和 Dock 的诊断来源均为 `Captured backdrop`。

画面可包含 Wallpaper Engine 等已经绘制到桌面的动态壁纸，以及后方应用窗口。采样失败时，先尝试 Windows Shell 提供的可读静态壁纸；没有可读来源则使用系统背景。本机 Shell 壁纸测试未找到可读静态图片，当前实际背景来自区域采样。

折射、内部柔化及边缘由 `LiquidLensRenderer` 和 WPF 表面自行实现，基础与回退仍使用 Windows DWM。此前只读研究了用户提供的 `D:\GlassDesk`，本版没有复制其源码、着色器或素材，也没有新增第三方组件或额外 SDK。

## 三个外观选项

在“设置 → 外观”中调整，修改会自动保存：

| 设置 | 默认值 | 行为 |
| --- | --- | --- |
| 液态玻璃 | 开启 | 绘制后方画面的折射与柔化；关闭后恢复系统磨砂，不支持磨砂时使用不透明背景 |
| 动态透景 | 开启 | 管理窗口活跃时更新；Dock 仅在鼠标停留时更新 |
| 玻璃清晰度 | 65% | 10%–100%；低值更柔和，高值保留更多后方细节 |

窗口不活跃或 Dock 空闲时，持续采样计时器会停止。关闭“动态透景”后，仍会在打开、位置或尺寸变化等事件中重绘一次。省电模式关闭折射处理；关闭动画、电池供电等减少动态效果的条件下，也不启动持续透景更新。

动态透景使用 CPU 计算背景图像，会增加窗口使用中的占用。更新受 120 ms 的请求计时和 80 ms 的合并延迟约束，还需加上采样与渲染耗时；它不是 60 fps 视频透传或实时光线追踪。希望降低开销时，可先关闭“动态透景”，保留按事件更新的玻璃；也可以关闭“液态玻璃”或开启省电模式。

## 采样与回退

只取样窗口或 Dock 周围的有限区域。背景像素在本机内存中处理，普通运行不写入配置、日志或截图文件，也不上传。采样时临时排除本软件自身窗口，结束时在清理路径中恢复原采样状态，避免画面递归；不隐藏窗口，不改变其他进程的窗口属性。

这条动态采样路径需要 Windows 10 2004 及以上和可用的桌面合成。更早版本、无法排除自身窗口或采样失败时，回退到可读静态壁纸或系统背景。受系统保护而无法采样的内容不保证可透出。Windows 11 22621 及以上保留 Desktop Acrylic；高对比度、系统透明关闭和省电等条件按系统回退，软件不会替用户修改 Windows 的透明设置。

## 字体和应用功能

应用与桌面页的名称继续默认跟随 Windows 的 Icon 字体，包括字体、字号、字重及样式；Dock 的 WPF 提示同步字体、字号、粗细和斜体。使用 changesize 时，在 **Icon** 中调整并点击 **Apply**，再切回或重新打开 LumaDock；仍未更新时，用“设置 → 应用 → 系统图标字体 → 刷新字体”。也可关闭“跟随 Windows 图标字体”后单独设置名称字号和加粗。详细流程见 [README](../README.md)。

Dock 固定、排序、启动和窗口切换，应用搜索、虚拟分组及桌面快捷方式管理保持原有使用方式。开机启动和桌面图标显示仍由用户主动操作并确认，不移动或删除原始文件。

## 最终包短时性能

同一份最终 0.4 自包含二进制在 Windows 11 x64、16 个逻辑处理器上顺序采样：

| 状态 | 采样 | 平均全机 CPU | 私有工作集峰值 |
| --- | --- | ---: | ---: |
| Dock 空闲，全部样本非前台 | 预热 20 秒，测量 60 秒 | 0.02251% | 55.281 MB |
| 启动台前台，动态透景开启 | 预热 25 秒，测量 60 秒 | 0.9445417% | 90.270 MB |

启动台首帧约 342.8 ms。前台 CPU 的单核口径为 15.1128%，仍有明显开销；需要降低使用中的占用时，可关闭“动态透景”或使用省电模式。本轮没有量化每个开关的独立收益。私有工作集低于 120 MB 只适用于此次短测，不能视为长期保证；启动台私有提交峰值 152.492 MB、总工作集 232.777 MB 是不同指标。

完整哈希、原始 CSV、候选版高占用记录及诊断边界见 [性能记录](performance.md)。0.2 / 0.1 数值仅保留为历史。没有测量 GPU 占用或承诺 60 fps。100 次窗口循环虽然无异常，强制 GC 后保留托管堆增加 7,147,168 字节，仍需长跑调查资源趋势；详见 [验证记录](validation.md)。
