## 应用发现与图标

- 后台 STA 读取用户和公共开始菜单、用户和公共桌面的 `.lnk`、`.url`、`.exe`。开始菜单递归扫描并跳过重解析点，桌面只扫描顶层。
- `Shell.Application` 的 `shell:AppsFolder` 提供 Windows 注册应用视图，可能包含传统和打包应用；记录数量不代表某一种应用类型的数量。
- 使用 Shell 名称、`System.AppUserModel.ID`、`System.Link.TargetParsingPath` 和真实快捷方式目标，不扫描全部磁盘。未注册的便携软件通过手动路径添加。
- 按目标与参数合并重复记录，保留不同启动参数。启动 `.lnk` 时由 Shell 读取原参数，不重复附加。
- 图标在后台 STA 中由 `IShellItemImageFactory` 提取，回退至 `SHGetFileInfo`。返回冻结 WPF 位图，释放 HBITMAP、HICON 与 COM 引用，并使用有界缓存。缺失图标返回空值。

Shell 扩展由系统或应用提供，可能损坏、挂起或返回缺失资源；提取工作不阻塞管理窗口关闭。应用图标仅在运行时读取设备已有资源。

## 运行状态与窗口切换

只识别可见、非工具、非 DWM cloaked 的真实顶层窗口。Dock 的胶囊运行标记表示已识别的应用窗口，不等同于后台进程或服务状态。与前台窗口匹配时显示更长的强调色标记；状态不靠固定项或应用名称推测。

`SetWinEventHook` 监听前台切换、最小化、窗口创建、销毁与显隐；合并事件后更新，不做固定频率的全进程轮询。位置变化只用于相关前台窗口的全屏判定，避免拖动窗口造成无效枚举。

匹配完整进程路径或完整 AUMID。代理宿主应用可进一步读取子窗口身份；同一 exe 的多个快捷方式或配置未必能区分，带参数的系统文件管理器快捷方式不按名称猜测身份。跨权限和受保护进程可能无法查询。

激活时还原最小化窗口并请求 `SetForegroundWindow`，同应用多个窗口可循环切换。Windows 前台策略可能拒绝请求；返回失败，不注入进程，也不伪造成功。Shell 接收启动请求不代表目标已经成功运行，损坏或卸载残留需要用户处理。

## 屏幕、全屏与任务栏

`EnumDisplayMonitors` 和 `GetMonitorInfo` 提供物理像素的完整与工作区边界，允许负坐标。应用声明 PerMonitorV2，按目标 DPI 换算 WPF DIP；显示器断开时回退主屏。

Dock 使用工具窗口与 `WS_EX_NOACTIVATE`，不占任务栏条目、不抢键盘焦点，不注册 AppBar，也不改变系统工作区。

全屏判定比较前台窗口和所选显示器完整边界，排除系统桌面与任务栏；只有所选显示器被覆盖时才抑制 Dock。独占图形程序、远程游戏与特殊覆盖层仍需实际验证。

## 可选系统操作

- **桌面图标显示**：确认后对系统桌面的 `SysListView32` 调用 `ShowWindow`，不写注册表，不移动或删除文件。窗口层级并非稳定的公共桌面管理接口，查找失败时明确返回失败。系统桌面进程重启后，状态可能恢复；Windows 桌面右键“查看 → 显示桌面图标”是恢复入口。
- **开机启动**：确认后仅创建或移除当前用户启动文件夹内的 `LumaDock.lnk`，不写 Run 注册表，不创建服务或计划任务。
- **全局热键**：用 `RegisterHotKey` 注册 Ctrl + Alt + Space。冲突时仍可从 Dock 或托盘打开应用；退出时注销热键与窗口事件钩子。

## 集成测试

```powershell
.\scripts\test-windows.ps1
```

该测试需要已登录的 Windows 交互会话。它核对：

1. Shell 发现记录非空、标识唯一、名称和启动元数据有效。
2. 桌面记录指向现存的支持文件，允许桌面为空。
3. 真实图标样本能够异步提取、冻结并复用缓存。
4. 显示器工作区尺寸及完整边界有效，允许负坐标。
5. 窗口快照 HWND 唯一，身份元数据可用于匹配。

测试不主动启动应用，不写系统设置，也不编辑桌面或开始菜单快捷方式。报告写入 `artifacts/tests/windows-results.json`，汇总结果不包含应用名称、个人路径、窗口标题或 AUMID。测试期间安装、卸载或删除快捷方式会影响结果，可在系统稳定后重跑。

功能集成检查不能代替多屏、混合 DPI、提权程序、独占游戏或长期驻留验收。已取得的结果与尚未覆盖场景见 [验证记录](validation.md)。
