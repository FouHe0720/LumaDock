- 目标为 Windows 10 / 11 x64；已验证平台是上述 Windows 11 环境。

- 性能结果只对应记录的二进制、状态和测试时长，不承诺 GPU 占用或 60 fps。
- 暂无桌面时钟、分组标签改名/排序、代码签名、安装器或自动更新。
