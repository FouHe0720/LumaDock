## 恢复原始桌面状态

LumaDock 不替换 Explorer、不注入系统进程、不修改系统文件。若曾主动隐藏桌面图标，可在本软件“桌面”页重新显示，或用 Windows 桌面右键“查看 → 显示桌面图标”恢复。若曾启用开机启动，可在设置中关闭，或只移除当前用户“启动”文件夹内本软件创建的 `LumaDock.lnk`。卸载和数据保留方式见 [README](../README.md)。
