# LumaDock 0.11.2

**移到哪，就停在哪。**

[使用指南](USER-GUIDE.md) · [验证范围](validation.md) · [性能记录](performance.md)

## 自由移动，重新处理

修复 Dock 拖到任务栏区域后弹回的问题。拖住移动握柄或底座空白处，底座直接跟随指针，可以放到完整显示器中的位置，包括 Windows 任务栏占用的区域；松开后保存，刷新或重启后恢复。

旧版的位置夹取与保存检查没有覆盖完整的鼠标移动路径。本版将拖动输入、松手保存与后续重建一起验证，具体方法和结果记录在验证范围中。

## 大一点，小一点，随手拉

底座右端增加缩放握柄，竖向摆放时位于下端。沿长边或向外侧拖动，图标和底座一起连续缩放；图标大小范围为 **24–160 DIP**，也可使用偏好设置精确调节。

缩放联动图标和底座的比例，以可见底座中心为基准预览；不是只拉长外框、把图标挤扁。松手后再保存位置与尺寸，并按当前尺寸请求系统图标；不在拖动的每一帧重新创建整栏或写入配置。

按 **Esc** 可取消本次移动或缩放，恢复开始时的位置和尺寸。失去鼠标捕获、Dock 隐藏或关闭时同样取消预览，避免保存半途状态。

## 日常行为保留

应用和文件夹固定、任意位置插入、图标排序、悬停放大、倒影、名称字体、20 列应用库和真实桌面集继续保留。应用图标的拖动仍用于整理，不会变成整栏移动。

Dock 仍使用普通窗口层级，工作窗口保持在前。Windows 任务栏可能盖住重叠部分；本版不隐藏或更改系统任务栏。需要找回底座时，按 **Ctrl + Alt + Space** 打开应用库，在 **偏好设置 → Dock → 恢复位置** 回到底部居中。

## 下载与记录

下载 **LumaDock-0.11.2-win-x64.zip**，完整解压后双击 **LumaDock.exe**。便携包包含 .NET Desktop Runtime，无需另装 SDK 或 IDE，原有固定项、自选图标、栏目和外观继续保留。

本版测试与资源结果按最终 Windows 程序单独记录，历史版本的数据不作为本版性能保证。测量条件与未覆盖环境见[验证范围](validation.md)和[性能记录](performance.md)。

Windows 本机实测：58 DIP Dock 静置平均全机 CPU 0.00802%、私有工作集峰值 49.7 MB；160 DIP Dock 为 53.4 MB；最大化应用库为 94.7 MB、0.00553%。三轮为同一最终程序，分别预热 20/20/120 秒后请求采样 30 秒，各固定 2 个程序和 1 个实际文件夹、倒影 90%。短测不代表持续操作或长期驻留。最大化应用库总工作集峰值 235.9 MB，与私有工作集口径不同。
