# LumaDock 0.5.0

历史预发布版本。0.5 增加短时边缘流光、四种强调色和内置名称字体调节。当前操作说明见 [使用指南](USER-GUIDE.md)。

## 交互与个性化

- 沿圆角移动的窄幅反光随指针位置与方向变化，停下后收束。默认幅度 45%，可调为零。
- 每次有效输入触发短动画；最后一次输入后约 620 ms 停止，离开后约 180 ms 消退。静止坐标不续播，隐藏或减少动效时停止。
- 提供潮蓝、青瓷、琥珀、烟紫，按钮、选中状态和玻璃边缘共用强调色。
- 增加已安装字体选择、名称字号、加粗、斜体及即时预览，仅作用于 LumaDock。
- 导航调整为“应用库、桌面集、偏好设置、关于”，设置顶部增加材质、文字与 Dock 直达入口。

流光是短时二维反光；动态透景单独负责背景限频更新，二者可以分别关闭。名称字体默认跟随 Windows 图标字体；关闭跟随后可使用独立设置，详见 [名称字体](SYSTEM-FONTS.md)。

应用与桌面页共享分类和固定状态。分组是虚拟管理记录，不移动真实文件。新增选项兼容原配置，模式版本保持为 1。
