# LumaDock 0.5.0

Windows x64 便携预发布版。发布包名为 `LumaDock-0.5.0-win-x64.zip`，解压整个目录后运行 `LumaDock.exe`，不需要 IDE 或另外安装 .NET。Release 构建和本轮组件、WPF 回归已通过，本机已完成深色青瓷界面、字体预览检查和两轮短时资源采样。完整范围见 [验证记录](validation.md) 和 [性能记录](performance.md)，不把 0.4 测试结果计作 0.5 验收。

## 玻璃边缘的流光

保留已有的真实背景折射和内部柔化，新增沿圆角移动的短暂反光。指针移动时，边缘的窄幅亮线跟随位置与移动方向变化，停止后渐收；外缘、内缘和底部暗边分别处理厚度。

“偏好设置 → 材质与颜色”提供“玻璃流动”和“流动幅度”。默认开启，幅度 45%，可调至 0% 完全停用。每次有效指针输入只启动一段短动画，最后一次输入后最多约 620 ms 停止，离开后最多约 180 ms 消退；隐藏、不活跃、省电或关闭界面动画等减少动态效果的条件会停止。重复的同坐标输入不让动画一直续期。

流光是二维反光的短动画，不是持续运行的流体模拟。“动态透景”负责后方画面的有限频率更新，可单独关闭；“液态玻璃”负责真实背景的折射与柔化；“玻璃清晰度”控制后方细节。更多采样与回退说明见 [0.4 发布说明](RELEASE-0.4.md)。

## 四种强调色

潮蓝、青瓷、琥珀、烟紫可在同一位置选择。颜色用于主要按钮、选中状态和边缘反光，深色与浅色有各自的配色。选择写入本地配置，不修改 Windows 的主题或强调色。

界面导航改为：

| 名称 | 内容 |
| --- | --- |
| 应用库 | 开始菜单、商店、桌面和手动添加的应用 |
| 桌面集 | 来自桌面的应用快捷方式 |
| 偏好设置 | 材质、文字、Dock、启动与数据 |
| 关于 | 版本与许可证 |

应用库和桌面集可以出现同一个软件，分类与 Dock 固定状态共享。它们是管理记录，不移动真实文件。

## 在软件里调整名称字体

“偏好设置”顶部的“文字”按钮直达“名称字体”。关闭“跟随 Windows 图标字体”后，可以选择已安装字体、名称字号、加粗和斜体，下方用实际应用名称实时预览。

字号范围为 7.5–30 磅，内部保存为 10–40 DIP。拖动时预览即时改变，松开或结束键盘操作后保存；应用库、桌面集的名称及 Dock 提示使用该设置，大字会调整网格密度。

这些控件只更改 LumaDock 字体，不修改 Windows 全局字体，不包含 changesize 程序。需要延用 changesize 的 Icon 设置时，保持“跟随 Windows 图标字体”开启，在外部工具执行 Apply 后切回 LumaDock，或点击“刷新字体”。详细说明见 [名称字体](SYSTEM-FONTS.md)。

## 保留的功能和边界

Dock 固定、排序、启动与真实窗口切换，应用搜索、虚拟分组、桌面快捷方式管理和配置备份继续使用原有数据。新增设置缺省为默认值，配置模式仍为 1。开机启动及桌面图标显示仍需要用户主动操作并确认，不自动改写系统设置。

折射、边缘流光、图标和布局继续使用原生 WPF、Win32 与 Windows Shell；本轮没有新增浏览器运行时、后台服务或第三方库。参考 GlassDesk 的视觉表现后独立实现，未复制其源码、着色器或素材。

仓库增加 Windows GitHub Actions 构建，运行确定性的组件测试并生成便携包。远程运行结果以 GitHub Actions 工作流为准；CI 不代替真实桌面视觉、Shell、字体工具、DPI 或性能验收。
