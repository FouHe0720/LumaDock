# LumaDock 0.6.0

Windows x64 便携预发布版。解压完整发布包，运行 `LumaDock.exe`；运行时已包含在包内，无需 IDE 或额外安装 .NET。

## 界面

- 侧栏采用不对称圆角、图标方章和强调色细线，区分工作区与选项。
- 分类使用折角式标签，显示随搜索和页面范围更新的真实数量。
- 偏好设置使用独立的轻透分组卡，材质、Dock、名称字体、应用整理、性能和数据各有清楚的入口。
- 搜索、工具组合栏、悬停框与名称预览使用统一的交错圆角；开关和滑块同步调整造型。
- 保留四种配色、背景折射、有限流光和应用名称字体设置。
