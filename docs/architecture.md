# 架构

[开发与构建](DEVELOPMENT.md) · [Windows 集成](WINDOWS-INTEGRATION.md) · [材质实现](WINDOW-BACKDROP.md)

LumaDock 是单进程、普通用户权限的 Windows WPF 应用，目标框架为 `net10.0-windows`，运行架构为 x64。

## 模块

| 模块 | 职责 | 资源边界 |
| --- | --- | --- |
| App | 生命周期、托盘、热键、Dock、管理窗口、主题与设置 | WPF 状态与交互留在 UI 线程 |
| Core | 目录、稳定 ID、合并、搜索、分类、设置校验与图像算法 | 不依赖 WPF、Shell 或磁盘 |
| Windows | Shell/COM、图标、启动、窗口跟踪、屏幕和原生背景 | 释放句柄、COM 引用和事件钩子 |
| Storage | JSON、原子替换、备份、恢复和日志 | 配置版本校验，日志轮转 |
| Tests | 组件契约、真实窗口与系统集成 | 隔离测试配置，不擅自更改系统偏好 |

管理窗口使用 `AppTileViewModel` 绑定名称与图标，应用控制器管理命令和持久状态。小型布局与交互采用代码构建 WPF 控件，核心业务与 Windows 交互保持项目边界。

## 发现、合并与启动

启动或手动刷新时，后台 STA 线程枚举开始菜单、桌面快捷方式和 `shell:AppsFolder`。快捷方式保留路径与参数，注册应用保留可解析的应用用户模型 ID。扫描结果合并时更新启动元数据，保留用户分类、顺序、固定和隐藏状态。

隐藏记录作为持久标记保留，避免下次扫描重新出现。分类属于虚拟管理数据，不改变安装位置。UI 搜索按完整输入字符串匹配名称或启动路径；Core 的词项搜索 API 是独立组件接口。

启动交由 Windows Shell。窗口匹配使用可读取的真实可执行文件路径或应用身份，无法准确识别时不显示运行指示。窗口激活遵守 Windows 前台与权限限制，失败会明确返回，不注入目标进程。

## 线程与空闲行为

- 图标在后台 STA 中提取，冻结位图后交付 UI，使用有界缓存。
- 窗口变化通过 `SetWinEventHook` 监听并合并，不按固定频率轮询全部进程。
- Dock 自动隐藏只在离开后启动一次延迟；停稳后无持续动画帧回调。
- 主题、电源、会话与屏幕变化通过系统事件更新，关闭时释放订阅和句柄。
- 短过渡只作用于内容层，保持普通非分层 HWND 与原生合成路径。

搜索框的视觉光标随输入、选区和焦点变化更新，以减少重复渲染。相关兼容处理依赖固定的 WPF 模板，升级运行时或模板时需要复测输入、中文 IME 与资源占用。

## 材质与流光

`WindowBackdrop` 管理 DWM 原生背景及回退。`LiquidGlassSurface` 在后台处理有限后方区域的采样、曲边像素偏移和内部柔化；同尺寸复用位图，重复场景可跳过图像渲染。空闲 Dock、隐藏和不活跃窗口不持续更新透景。采样时仅临时排除自身窗口，在清理路径恢复。

`GlassRim` 独立绘制分层细边缘及短时反光。有效指针位置变化触发 34 ms 间隔的 `DispatcherTimer`，最后一次输入后约 620 ms 停止，离开后约 180 ms 消退。重复的同坐标输入不续期；隐藏、卸载、不活跃或关闭动效时停止。没有常驻 `CompositionTarget.Rendering` 订阅，也不执行流体模拟。

动态透景与流光是不同的更新机制，可以单独关闭。具体系统支持、采样并发与回退条件见 [材质实现](WINDOW-BACKDROP.md)。

## 主题与字体

`Theme.Apply` 统一生成控件资源。`Accent` 为 `Lagoon`、`Jade`、`Amber` 或 `Iris`，对应潮蓝、青瓷、琥珀、烟紫；深浅主题使用各自的色值。边缘反光与控件使用同一强调色。

`AppController.NameFont` 返回系统图标字体或用户自选家族、字号与样式；动态资源更新应用名称和 Dock 提示。设置预览使用相同字体值，滑动时即时显示，提交交互后保存。大字号由 `AppGridLayout` 调整列数和两行名称空间，DPI 缩放交由 WPF。

手动字体不调用写入 Windows 全局字体的 API。配置导入检查家族长度、控制字符和 URI/路径分隔符，避免把家族选择变成外部字体加载入口。

## 持久化与系统操作

默认数据目录为 `%LOCALAPPDATA%\LumaDock`，可通过 `--data-dir` 隔离。模式版本为 1；写入临时文件并刷新到磁盘后替换，已有配置备份为 `.bak`。损坏文件原样保留，再回退备份或默认值；较新配置拒绝向下覆盖。日志轮转，不主动上传。

开机启动与桌面图标显示仅在用户操作并确认后改变。导入和恢复默认值不授权系统修改。开机启动使用当前用户启动文件夹内的自有快捷方式；桌面显隐调整系统桌面窗口的显示状态，不移动文件。

## 验证与发布

构建与测试入口见 [开发文档](DEVELOPMENT.md)。GitHub Actions 构建解决方案并执行确定性组件测试；真实桌面、Shell、DPI、游戏与长期驻留需要另行验证。公开发行只包含程序、许可与经过检查的证据，不包含个人配置、应用清单、日志或屏幕内容。
