# LumaDock 0.10.3

**应用库与 Dock 细节更新。**

[使用指南](USER-GUIDE.md) · [性能记录](performance.md) · [验证范围](validation.md)

## 应用库／桌面集

恢复两个直接的入口。应用库展示已发现与手动添加的应用；桌面集展示与仍存在的桌面快捷方式关联的应用。两页共用整理记录、搜索、启动方式与固定状态，自建栏目继续保留。

整理添加应用的交互，支持多选程序与快捷方式。文件选择保留原始快捷方式，继续使用它的图标、参数与工作目录。入口在后台批量读取和整理；能够添加的入口保留，无法读取的文件显示结果，避免一次失败中断整批添加。完成后转到应用库，清除搜索与栏目筛选，并定位添加结果。

网格重新分配标题、搜索和分页所占空间，正常窗口尺寸下优先显示三排；小窗口和大字号继续按可读空间调整，不裁切应用名称。快捷键旁补上“快速打开应用库”说明，也可直接点击。

## Dock

运行标记改为有衬底与细边缘的胶囊条，与倒影保持可辨认的层次。已识别的前台应用使用更长的强调色标记。状态仍来自 Windows 真实窗口，不把固定项、后台服务或进程存在直接当作已运行。

悬停放大与抬起更突出，邻近图标同步让位，倒影保持清楚。新配置的悬停强度为 62%、倒影为 50%，倒影调节上限提高至 95%；旧配置已有的外观选择继续保留。

图标与倒影复用缓存图像。动画只在交互和回落时运行，停稳后停止；运行标记保持静态，不增加常驻动画。

## 工作窗口在前

延续 0.10.2 的普通窗口层级。打开其他应用时，Dock 保持在工作窗口下方；返回桌面继续使用 Dock，也可以按 Ctrl + Alt + Space 打开应用库。

本版使用原有配置格式 2，保留固定项、自建栏目、自选图标及其他偏好。便携包包含运行时，完整解压后运行 `LumaDock.exe`，无需另装 .NET 或 IDE。

实际构建、组件与 Windows 交互检查见[验证记录](validation.md)，资源采样条件见[性能记录](performance.md)。
