# LumaDock 0.7.0

Dock 外观与交互更新。Windows x64 便携预发布版；完整解压后运行 `LumaDock.exe`，无需另装 .NET 或 IDE。

## Dock

- 三种轮廓：圆润胶囊、交错圆角的卵石、低矮利落的轨道。
- 放大图标朝屏幕内侧抬起，邻近图标轻轻让位；透明活动区避免把放大部分裁掉。
- 独立的玻璃底座、细边、内缘、窄阴影与颜色嵌线。图标停稳后结束动画，保留当前悬停状态。
- 放大强度可调；四边停靠时方向相应变化。高 DPI 按实际图标尺寸请求 Shell 图像。
- 保留点击启动与窗口切换、运行圆点、固定排序、自动隐藏、滚动与显示器选择。

## 个性化

在“偏好设置 → Dock”选择轮廓和悬停强度。在“材质”选择潮蓝、青瓷、琥珀、烟紫、玫瑰或石墨；颜色同步到按钮、选中状态和玻璃边缘。旧配置自动使用胶囊，已有应用整理与排列保留。

## 资源

悬停使用有限插值更新，停止后移除活动计时器。背景连续不变时逐步放慢采样，检测到变化后恢复；退避状态下新变化可能等待约一秒才被发现。放大动画独立于背景采样。

薄横条光学路径复用每行相同的采样计算，保留原输出分辨率与像素结果。组件微基准不等于整机 CPU、GPU 或交互帧率，实际结果与范围见 [性能记录](performance.md)。设置应用时也合并了重复的 Dock 重建。

完整操作见 [使用指南](USER-GUIDE.md)，本版测试见 [验证范围](validation.md)。Windows 10、真实混合 DPI 多屏、独占游戏与长时间驻留仍需专项验证。

本版 Release 构建零警告、零错误；42 项 Dock、21 项字体与设置、27 项 Core/Storage 检查通过，另完成光学、采样、更新节奏与 100 次窗口开合回归。60 秒短测中，Dock 平均全机 CPU 0.00947%、私有工作集峰值 49.652 MB；前台应用库、指针静止时为 0.04952% / 76.070 MB。完整口径与二进制哈希见性能记录。
