# LumaDock 0.10.0

Dock 多了一层淡淡倒影，底座更通透；应用集中到一个列表，栏目由自己来定。

## 玻璃与倒影

图标倒影来自正在显示的真实图标，随悬停放大、抬起与相邻图标的位移一起变化，向底座外侧渐隐。顶部、底部、左侧和右侧停靠都使用对应的镜像方向。

在 **偏好设置 → Dock** 开关“图标倒影”、调节强度；省电模式和高对比度时暂时关闭。倒影复用缓存图像，不截屏，也不另存一份图标位图。

底座的 **Dock 浓度** 范围扩展为 15–100%，默认 70%，低一些更通透，图标本身保持清楚。升级时将旧默认值 88% 调为 70%，其他已选择的值保留。管理窗口的“窗口浓度”仍是独立选项。

悬停按实际经过时间继续插值，反向移动时从当前姿态衔接。图标和流光停稳后停止计时，倒影没有独立动画循环。

## 一个应用列表

原先分开的应用库与桌面集归为一个 **应用** 入口，开始菜单、桌面、注册入口及手动应用共用去重后的记录。新应用不会自动归类，也不再生成开发工具、办公学习、浏览器等默认栏目。

点击 **新建栏目**，拖入应用或从应用右键菜单选择“放入栏目”。栏目右键可重命名或删除；不再需要归类时，选择“不放入栏目”。删除栏目后，应用仍在“全部”中，原程序、桌面快捷方式和 Dock 固定状态保留。

升级时移除旧内置分类，保留能够识别的自建栏目；这些栏目同样可以随时删除。重新扫描不会恢复已经删除的默认分类。

## 本机入口核对

刷新时同时核对启动文件、快捷方式目标和当前注册状态。已确认不可用的入口暂不显示，保留其自选图标、栏目和固定顺序，程序恢复后可重新出现；一次读取异常或不完整枚举不会直接删除记录。文件夹和普通文档快捷方式尽可能排除。

重复快捷方式按启动目标、参数、URL 和应用标识合并，固定 ID 映射到保留记录。同名且指向同一本地程序的不同启动方式集中到一张卡片；右键卡片或 Dock 图标 → **启动方式**，可以选择原有入口，参数和工作目录不丢失。

不同程序、网页、协议和打包应用身份仍分别保留，名称相同本身不会导致合并。Dock 使用原先固定的启动方式，并将同一应用的其他方式留在菜单里。

扫描覆盖开始菜单、桌面、AppsFolder 注册入口与手动添加的有效路径，不遍历整块磁盘。未注册的便携软件需要通过“添加应用”加入，不能把这些注册入口等同于设备上所有可执行文件。

## 升级与使用

便携包完整解压，运行 **LumaDock.exe** 即可使用；无需额外安装 .NET、SDK、IDE 或字体工具。Ctrl + Alt + Space 打开应用列表。

本版配置格式升级为版本 2，可迁移旧格式。需要回退 0.9 时，请使用升级前备份或独立数据目录，旧程序不能读取新格式。

实际构建、交互、资源与兼容性范围见 [验证记录](validation.md) 和 [性能记录](performance.md)。本版继续标记为预发布，完整操作见 [使用指南](USER-GUIDE.md)。
