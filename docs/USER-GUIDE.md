# LumaDock 使用指南

[返回首页](../README.md) · [下载 0.11.1 便携版](https://github.com/FouHe0720/LumaDock/releases/tag/v0.11.1) · [字体与文字](SYSTEM-FONTS.md)

## 1. 运行前需要什么

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / Windows 11，x64；推荐 Windows 11 |
| 程序包 | Releases 中以 `win-x64.zip` 结尾的便携包 |
| 安装依赖 | 便携包自带 .NET Desktop Runtime，无需另装 SDK 或 IDE |
| 权限 | 普通用户权限即可；受管理设备仍受组织策略限制 |
| 其他软件 | 无需额外主题工具、字体工具、图标包或后台服务 |

当前为预发布版本。Windows 11 已有构建和交互验证；Windows 10、真实混合 DPI 双屏、独占全屏游戏和长期驻留仍需专项覆盖，详见 [验证范围](validation.md)。玻璃材质取决于系统合成、透明效果和显卡驱动，部分条件下会使用更简单的背景。

## 2. 下载、解压与第一次启动

1. 在 [Releases](https://github.com/FouHe0720/LumaDock/releases) 选择需要的版本，下载 `LumaDock-版本号-win-x64.zip`。
2. 完整解压到可写且准备长期保留的位置，保留全部文件和子目录。
3. 双击 `LumaDock.exe`，等待首次应用扫描完成。
4. 点击 Dock 左端的 L 图标，或按 **Ctrl + Alt + Space**，打开“应用库”。主界面左下角的“快速打开应用库”也可点击。

不要只取出 exe，也不要直接在压缩包预览中运行。`source.zip` 和 GitHub 自动生成的源码包供开发使用；从源码构建请看 [开发文档](DEVELOPMENT.md)。

首次应用扫描读取当前用户和公共的开始菜单、桌面快捷方式，以及 Windows 的 AppsFolder 注册应用列表，汇集在“应用库”中。“桌面集”独立读取当前用户和公共桌面的实际文件与文件夹。查看、扫描和搜索不会修改这些文件，也不会自动创建分类栏目。

### 创建快捷方式

在解压目录找到 `LumaDock.exe`，使用 Windows 文件右键菜单中的“创建快捷方式”或“发送到 → 桌面快捷方式”。菜单位置会随 Windows 版本变化。

已有实例运行时再次打开，会显示同一个应用窗口。移动程序文件夹后，旧快捷方式需要重新创建。开发者还可以使用 [快捷方式脚本](DEVELOPMENT.md#创建快捷方式)。

### 调整工作台窗口

0.11.1 将 Logo、LumaDock 名称与“把整个桌面，变成你的主场”三项分别居中，上下留出更舒展的间距。应用库、桌面集、自建栏目和偏好设置仍在左侧，左下角保留快速启动提示。

- 拖动四条边或四个角，放大或缩小窗口。
- 点击右上角最大化按钮展开；再次点击还原。
- 双击顶部品牌区的空白处，也能在最大化与还原之间切换。
- 拖住顶部品牌区的空白处，移动整个窗口。

默认窗口为 1160×800，最小尺寸为 900×600。1120×760、每行 6 个、15 DIP 名称字号下仍可显示三排六列；使用更大字体或较小窗口时，网格优先保留可读的名称空间。

## 3. 应用库、桌面集与自建栏目

左侧 **应用库** 汇集扫描到的程序和手动添加的启动入口，支持搜索、自建栏目和 Dock 固定。**桌面集** 展示真实桌面上的文件夹、文档、图片和快捷方式，便于直接使用桌面内容。普通文件不会混入应用库。

### 桌面集：文件与文件夹

从 0.10.4 起，桌面集读取 Windows 提供的当前用户桌面位置，也读取公共桌面。已重定向到其他位置的桌面仍按系统返回的路径读取，只展示顶层内容，不展开子文件夹。隐藏、系统项目和 `desktop.ini` 不显示；“回收站”“此电脑”等虚拟系统图标不在这份文件清单中。

同一路径只显示一次；用户桌面和公共桌面中同名的两个实际项目分别保留，不按名称或应用目标合并。图标来自 Windows Shell，名称、字号、粗细和文字颜色沿用 LumaDock 的设置。

| 操作 | 使用方式 |
| --- | --- |
| 打开文件夹 | 双击，用资源管理器打开 |
| 打开文件或快捷方式 | 双击，交给 Windows 默认关联程序或原始快捷方式 |
| 查找项目 | 在搜索框输入名称，搜索覆盖桌面集全部分页 |
| 新建文件夹 | 空白处右键 → **新建 → 文件夹** |
| 新建文本 | 空白处右键 → **新建 → 文本文档 (.txt)** |
| 重命名 | 选中项目后按 **F2**，或右键 → **重命名** |
| 复制项目 | 选中项目，右键 → **复制** |
| 复制路径 | 右键项目 → **复制路径** |
| 将文件粘贴到桌面 | 先在其他位置复制文件，再在桌面集空白处右键 → **粘贴文件副本** |
| 手动更新 | 按 **F5**，或点击 **刷新** |
| 打开完整桌面目录 | 点击顶部 **打开桌面**，或空白处右键 → **打开桌面文件夹** |

**新建、重命名和粘贴是实际的文件操作。** 新项目保存在当前用户桌面，也会出现在 Windows 桌面上。新建与粘贴遇到同名项目会自动编号，原有项目保留；重命名遇到冲突会提示，不覆盖另一个文件。给普通文件改名时请保留需要的扩展名，避免改变默认打开方式。

粘贴当前支持普通文件，始终复制，原文件保留；不执行剪切或移动。文件夹和文件系统重解析点的复制请点击“打开桌面”交给资源管理器处理；普通 `.lnk` 快捷方式可按文件复制。不同文件可能有不同的访问权限，读取或写入失败时会显示结果；公共桌面中的部分项目可能需要额外权限。

桌面集可见时通过文件系统事件接收增加、移除与改名，短暂合并变更后重新读取。切到其他页面、隐藏或关闭窗口时停止监听；再次进入会刷新，不持续后台扫描。路径暂时不可用或监听失败时，可以使用 F5 重试，并在资源管理器中检查桌面目录。

桌面上的程序与快捷方式仍可通过右键菜单加入应用库或固定到 Dock，原入口与启动参数保留。从 0.11.1 起，本机实际文件夹可右键 **固定到 Dock**，也可以直接拖入 Dock；文件夹仅登记固定入口，不会混入应用库，也不会移动或复制目录。普通文件的打开由 Windows 默认关联处理，不将它们当作软件清单登记。

桌面集提供常用文件操作；其他“新建”模板、回收站、删除和完整的第三方 Shell 扩展菜单请使用资源管理器或 Windows 桌面。应用库的自建栏目仍是虚拟分组，不会在这里创建真实目录。

### 应用库：查找软件

同一启动身份的重复入口合并显示。初次使用没有默认分类，应用库的“全部”展示完整可见应用列表。

同名且指向同一本地程序的入口只显示一张卡片，不同启动参数和工作目录仍完整保留。其他程序、网页、协议、打包应用身份和共用宿主的独立入口分别保留，名称相同本身不会导致合并。整理只改变 LumaDock 的管理记录，不改变软件安装位置。

### 查找、启动与手动添加

- 在搜索框输入名称或启动路径的一部分；搜索按完整输入字符串匹配，不区分大小写。
- 点击应用启动它。如果能够识别已有运行窗口，会优先请求切换到该窗口。
- 点击“添加应用”，选择 `.exe`、`.lnk`、`.url` 或 `.appref-ms`，可一次多选。文件在后台读取，添加期间避免重复提交；成功后转到应用库并定位添加结果。无法读取的文件会显示结果，其余有效文件仍可添加。
- 添加应用只登记启动入口，不将文件移动到 Windows 桌面。取消选择不会添加记录；在桌面集新建文件则会实际写入用户桌面，两种操作用途不同。
- 安装新软件后，点击“刷新”，或在托盘菜单选择“重新扫描应用”。自建栏目、排列和隐藏记录会保留，新应用不会自动归类。

扫描覆盖开始菜单、桌面和 AppsFolder 注册入口，不遍历整块磁盘。未注册的便携软件、只放在某个文件夹中的程序，需要手动添加；不能把注册列表当作设备上全部可执行文件的清单。

### 应用排布与翻页

在正常窗口尺寸和默认字号下，网格优先显示三排应用。放大窗口可利用更多空间；缩小窗口或增大名称字号后，会减少行列数，保留两行名称的可读空间。当前页放不下的应用通过底部分页查看，搜索仍覆盖当前页以外的记录。

在 **偏好设置 → 应用整理 → 每行应用数** 中选择 **4、5、6、7、8、9、10、12、14、16、18 或 20 个**。这是希望显示的最大列数；20 列需要足够宽的窗口，名称字号变大或窗口变窄时会自动减少实际列数。放大或最大化窗口可使用更多空间。

布局按可用空间计算，不能保证每种窗口尺寸、系统字体和缩放下都有三排；只改变呈现，不改变应用记录或安装位置。

应用库中已确认程序文件不存在、快捷方式目标失效，或完整 AppsFolder 枚举确认注册已移除时，入口会暂时不显示。其自选图标、栏目及 Dock 固定顺序仍保留，程序恢复后刷新可重新出现。系统限制或不完整的 Shell 枚举不会仅凭“没扫到”删除记录。普通文件、文件夹快捷方式会尽可能从应用库排除，桌面上的实际项目仍由桌面集显示。

### 同一应用的不同启动方式

同名且指向同一本地程序的多个有效入口，例如不同参数的快捷方式，会收在同一张应用卡片中。右键卡片或 Dock 图标，打开 **启动方式**，按来源和参数选择需要的入口；将指针停在菜单项上，可查看路径、完整参数和工作目录。

这里的选择会将原始入口交给 Windows 启动，不会把参数改成默认值。是否打开新窗口取决于该程序自身。普通点击仍使用当前入口，Dock 会保留原先固定的启动方式。放入栏目、从 Dock 移除或删除管理记录时，同一应用的这些入口一起处理。

### 栏目、重命名与删除

1. 点击侧栏或标签区的“新建栏目”，输入名称。
2. 把应用拖到栏目标签上，或右键应用 → **放入栏目**，选择目标栏目。
3. 右键栏目，选择 **重命名栏目…** 或 **删除栏目**。
4. 不想继续归类时，右键应用 → **放入栏目 → 不放入栏目**。

删除栏目只清除该栏目的应用归属；应用仍在“全部”中，Dock 固定项和原始文件均保留。栏目名称为 1–40 个字符，不得与已有栏目重复；“全部”等内部名称保留。栏目是单层虚拟分组，不创建真实文件夹。

在应用库网格中，把应用拖到另一应用前面可调整排列。所有自建栏目都可以删除；刷新或重启不会重新生成默认分类。桌面集按真实目录内容排列，重命名操作会更改实际名称，不是虚拟栏目整理。

同一启动目标的重复快捷方式合并时，会保留 Dock 固定顺序、自选图标和桌面关联。

### 隐藏和恢复记录

右键应用选择“删除管理记录”，确认后从 LumaDock 隐藏，同时取消其 Dock 固定状态。这个操作不会卸载软件、删除快捷方式或移动原文件。

需要恢复时，打开“偏好设置 → 应用整理 → 已隐藏的应用”，点击“恢复全部”。当前恢复操作针对全部隐藏记录。

### 更换应用图标

在应用列表或 Dock 中右键应用，选择“更换图标…”，再选一个本地文件：

- `.ico`、`.png`、`.jpg`、`.jpeg`：使用文件中的图像。
- `.exe`、`.dll`、`.lnk`：读取程序或快捷方式提供的图标资源，不运行该程序。

同一应用在应用库和 Dock 中共用选择结果。右键“恢复原图标”可回到 Windows 提供的图标；未设置自定义图标时，恢复入口可能禁用或不显示。这个操作只保存 LumaDock 中的图标来源，不修改原程序、图片或桌面快捷方式。桌面集读取实际文件的 Shell 图标。

一些软件原始图标自带边框、底色或较宽留白。LumaDock 保留图标本来的内容；需要另一种外观时，可以选择该软件的其他真实资源或自己的图片。自定义图标按路径读取，请将文件放在准备长期保留的位置；文件不可读时会暂用系统图标来源。仅支持本地绝对路径，不支持网页、网络共享或设备路径。

在同一路径替换图片后，点击“刷新”可重新读取。移动或更名后请重新选择；不需要自定义图标时使用“恢复原图标”。

## 4. Dock 的日常使用

| 操作 | 结果 |
| --- | --- |
| 点击应用 | 启动，或请求切换到已识别的窗口 |
| 右键应用 → 固定到 Dock | 将入口加入 Dock |
| 拖动 Dock 图标 | 按插入标记调整固定顺序，支持首位、末位及任意两个图标之间 |
| 右键 Dock 应用 → 移除 | 只取消固定，应用列表记录保留 |
| 右键应用 → 启动方式 | 多个有效入口时出现；按原始路径、参数和工作目录启动 |
| 右键应用 → 更换图标… / 恢复原图标 | 调整该应用在 LumaDock 中的图标来源 |
| 将支持的程序、实际文件夹或其快捷方式拖入 Dock | 在插入标记的位置添加，原文件和目录保留 |
| 点击文件夹 | 通过 Windows 打开实际目录 |
| 桌面集右键文件夹 → 固定到 Dock | 将目录入口加到 Dock，应用库保持软件清单 |
| 将 Dock 图标拖到 Windows 桌面 | 创建真实快捷方式；原程序、已有桌面入口与 Dock 固定状态保留 |
| 悬停 | 当前图标放大、向内侧抬起，邻近图标轻轻让位，并显示名称 |
| 拖动握柄或底座空白处 | 移动整个 Dock，松开后保存自由位置 |
| 双击握柄或底座空白处 | 回到所选显示器底部居中 |

图标下方的胶囊条表示已识别的运行窗口；与前台窗口匹配的应用使用更长的强调色条。标记保持静态，衬底与边缘让它在明暗壁纸和倒影上更容易辨认。后台服务或无窗口进程不一定显示；跨权限、受保护窗口和某些代理宿主应用可能无法匹配或切换，可以使用 Windows 任务栏切换。

### 常用文件夹

从资源管理器、Windows 桌面或桌面集，把本机实际文件夹拖到 Dock 的插入标记处。文件夹快捷方式也可以拖入；同一目录的入口按目标路径整理，原快捷方式文件保留。只登记目录位置，不扫描其内部文件。

点击后通过 Windows 打开目录，文件夹快捷方式中的额外程序参数不会被执行。文件夹不显示程序的运行胶囊，也不尝试把任意资源管理器窗口当作该目录的运行状态。

移除仅取消固定，不删除目录。目标目录移走或不可读时，刷新后可能暂不显示，原固定顺序仍保留；恢复目录后刷新，或重新拖入新路径。“回收站”等没有实际目录的虚拟系统文件夹不在此功能范围内；网络共享目录未做专项验证。

右键 Dock 空白区域可以打开应用库、添加应用、恢复底部居中、打开偏好设置或退出。托盘菜单还提供重新扫描与重启 Dock。

### 工作窗口在前

从 0.10.2 起，Dock 使用普通窗口层级。打开或切换到其他应用时，应用保持在 Dock 上方；移动 Dock、改变显示器或刷新应用不会把它重新置顶。这一行为自动生效。

工作窗口遮住 Dock 时，可以使用 Windows 的“显示桌面”回到桌面，或按 **Ctrl + Alt + Space** 打开应用列表。Dock 的固定、拖排、倒影与外观选项继续按原来的方式使用。

### 轮廓与悬停

在“偏好设置 → Dock”选择胶囊、卵石或轨道。胶囊圆润，卵石使用交错圆角，轨道更利落。轮廓随停靠方向调整，放大图标保留独立空间。

“悬停放大强度”调节图标放大与抬起幅度。新配置默认 62%，已有配置保留所选数值；需要更突出时提高强度。设为 0% 或关闭界面动画可停止这组动效；省电模式也会减少动态效果。图标停稳后不持续播放动画。

### 图标倒影、鲜艳度与通透度

在 **偏好设置 → Dock** 中开启“图标倒影”，调整“倒影强度”。倒影来自当前真实图标，沿底座向外镜像并渐隐，随悬停放大与位移一起变化；更换图标时也会更新。新配置默认开启，强度为 50%，可在 **0–95%** 间调节，已有配置保留所选数值。0.10.3 提高渐隐中段的清晰度，并减轻图标抬起时的倒影衰减。省电或高对比度模式会暂时关闭倒影。

在同一组设置中调节 **图标鲜艳度**，范围为 **0–100%**，默认 28%。提高数值会提亮图标、增加色彩，倒影同步变化；设为 0% 使用原始颜色。它只影响 Dock，应用列表、Windows 桌面和原图标文件保持原样；透明边缘也保留。高对比度模式使用原色。

在 **偏好设置 → 材质 → Dock 浓度** 中调节底座，范围扩大为 **2–100%**，默认 70%。数值越低越通透，图标本身保持清楚。当前选好的浓度会保留；从更早版本迁移时，只将旧默认值 88% 调为 70%。

想让倒影更明显，可以提高倒影强度，再按壁纸明暗调整底座浓度和图标鲜艳度。数值松开后自动保存。鲜艳度只在图标加载或设置改变后处理并缓存，倒影与流光也不需要常驻播放动画。

### 位置、自动隐藏与双屏

**自由摆放：** 从握柄或底座空白处开始拖动，移到顺手的位置后松开。不要从应用图标上起拖，图标仍用于启动、固定与排序。位置在松开时保存，刷新或重启后恢复；调整图标大小和间距时，仍按已保存的相对位置摆放。

从 0.11.1 起，自由拖动使用完整显示器范围，**可以进入 Windows 任务栏所在区域**。四边停靠仍沿系统工作区摆放。拖到另一块屏幕后，落点所在屏幕成为新的位置锚点；所选屏幕断开时回到主屏。缩放或底座尺寸变化后，会按可见底座把位置限制在屏幕内；为放大效果预留的透明区域可以越过屏幕边缘。真实混合 DPI 双屏的验收范围见[验证记录](validation.md)。

Dock 仍是普通窗口，不会为了覆盖任务栏而置顶。Windows 任务栏位于上方时，可能遮住重叠部分；LumaDock 不自动隐藏或更改任务栏设置。找不到 Dock 时，可按 **Ctrl + Alt + Space** 打开应用库，再进入 **偏好设置 → Dock → 恢复位置**。

**四边停靠：** 在 **偏好设置 → Dock → 摆放方式** 选择“四边停靠”，再从“位置”选择顶部、底部、左侧或右侧。直接改变“位置”也会恢复四边停靠。

**恢复位置：** 双击握柄或底座空白处，或右键 Dock → **恢复底部居中**。设置中也有 **恢复位置** 按钮。它会回到所选显示器底部居中，保留图标顺序、自选图标、其他外观及显示器选择；该屏幕不可用时使用主屏。

**自动隐藏只在四边停靠时生效。** 自由摆放时不因鼠标离开而收起，并保留原有自动隐藏偏好；回到停靠后重新生效。停靠模式开启自动隐藏后，鼠标离开会短暂延迟收起，移到所选屏幕相应的工作区边缘可重新显示。应用覆盖相应边缘时，请先返回桌面再唤出 Dock。前台窗口覆盖所选屏幕时会尝试隐藏 Dock，特殊全屏和独占游戏仍可能需要单独调整。

双屏使用时，也可以在“显示器”下拉中选择目标屏幕；“主显示器（自动）”使用系统当前主屏。每块屏幕的缩放由 Windows 与 WPF 处理，若更改缩放后位置异常，可使用“恢复位置”或托盘菜单“重启 Dock”重新定位。

## 5. 颜色与玻璃

打开“偏好设置”，点击顶部“材质”。

| 设置 | 用途 |
| --- | --- |
| 强调色 | 潮蓝、青瓷、琥珀、烟紫、玫瑰、石墨，用于按钮、选中状态与边缘反光 |
| 主题 | 跟随系统、深色或浅色 |
| 液态玻璃 | 控制自定义透景、静态折射与相关流光；关闭后管理窗口保留系统支持的背景 |
| 动态透景 | 默认开启；后方画面交给系统合成，不叠加低频背景快照 |
| 透景风格 | 动态模式下选择清透或磨砂，默认清透；清透保留壁纸细节，磨砂柔化后方画面 |
| 窗口浓度 | 清透模式下显示，25–90%，默认 65%；调节管理窗口的底色浓度，不改变 Dock 透明度 |
| 玻璃流动 | 指针移动时短暂的边缘反光，停下后收住 |
| 流动幅度 | 反光强度，设为 0% 可停止流光 |
| 静态折射清晰度 | 关闭动态透景后显示；低值更柔和，高值保留更多后方细节 |
| Dock 浓度、轮廓、圆角、图标大小与间距 | 调整 Dock 外形和密度；浓度越低越通透，轮廓决定圆角的整体比例 |

### 动态与静态怎么选

使用动态壁纸时，保持“动态透景”开启，并选择“清透”。管理窗口会保留后方画面细节，Dock 使用真实透明底座；两者都由系统合成，不叠加低频背景快照。

清透模式的“窗口浓度”默认 65%。需要更多壁纸细节时降低浓度，需要更安静的阅读背景时提高浓度；如果偏爱柔和的背景，可手动选择“磨砂”。窗口浓度用于管理窗口，Dock 的透明度由单独的选项调节。

动态模式保留矢量边缘与流光，不执行实时曲边像素折射，也不承诺固定帧率或零延迟。当前清透路径在 Windows 11 验证环境下测试；Windows 10 仍待专项验证。系统透明效果关闭、高对比度、节电或不支持合成时使用不透明回退，应用不会替用户更改这些系统设置。

关闭“动态透景”后使用静态折射。打开、移动、调整窗口尺寸或相关背景事件会更新一次背景，平时保留该画面；动画壁纸在框内不会持续跟随。这时可调整“静态折射清晰度”。

流光、图标放大和背景模式可以分别选择。希望进一步减少材质与动效时，可开启“省电模式”。图标停稳后结束动画，空闲 Dock 不持续播放流光。

静态折射的背景像素只在本地内存中处理，普通运行不写入背景截图，也不上传。其短暂采样排除可能使同时运行的录屏或截图程序漏掉 LumaDock；默认动态透景不使用这条应用采样路径。开发诊断模式可能另存渲染图，分享前需要检查内容。

## 6. 字体与文字

1. 打开“偏好设置”，点击顶部“文字”，定位到“字体与文字”。
2. 关闭“跟随 Windows 图标字体”。
3. 选择已安装字体，调整名称字号、加粗或斜体。
4. 查看下方“文字预览”，松开滑块或结束键盘操作后自动保存。

字体、粗细和斜体同时用于侧栏、栏目、标题、搜索与设置文字，以及应用名称和 Dock 名称提示。名称字号范围为 **7.5–30 磅**；大字号会自动减少列数，并为两行名称留出空间。标题、导航和说明保留各自的字号，避免侧栏被放大挤满；标题与选中标签至少保持半粗。

“文字颜色”可选自动配色或五种预设；“自选颜色…”支持 `#RRGGBB`，例如 `#D7ECF4`，留空恢复自动。颜色用于主要标签和应用名称，说明、计数及强调色按钮保留各自的配色。自选颜色在主题切换时保留，若与背景接近，可改回“自动”；高对比度模式优先使用 Windows 文字颜色。

这些控件只调整 LumaDock。若希望沿用 Windows 当前图标标题字体，保持“跟随 Windows 图标字体”开启；字体或粗细在系统中实际生效后切回 LumaDock，必要时点击“系统图标字体 → 刷新字体”。跟随系统时也能单独选择文字颜色。详细范围见 [字体与文字说明](SYSTEM-FONTS.md)。

## 7. 开机启动、关闭与退出

在“偏好设置 → 性能与启动”中启用“随 Windows 启动”，确认后会在当前用户的启动文件夹创建 LumaDock 自有快捷方式。此项默认关闭，不写系统 Run 注册表。

请先将程序放在长期保留的位置，再启用开机启动。移动文件夹前先关闭此项，移动后重新开启。Windows 启动管理或组织策略仍可能禁用入口。

默认关闭管理窗口后继续驻留托盘。完全结束请使用托盘或 Dock 菜单的“退出 LumaDock”。关闭“关闭窗口后驻留托盘”后，关闭窗口也会退出程序。

## 8. 配置备份与恢复

“偏好设置 → 数据”提供：

- **导出配置**：保存栏目、排列、固定状态、外观、Dock 自由位置与自定义图标路径的 JSON 备份。
- **导入配置**：确认后替换整理结果与偏好，建议先导出当前配置。
- **恢复默认值**：重置 LumaDock 整理与偏好，不移动原文件。

导入与重置不会自动启用开机启动，也不会改变 Windows 桌面图标显示。配置中的程序路径只对仍存在的应用有效；导入另一台设备时，可能需要重新添加路径。

配置导出记录图标文件路径，不复制图标文件。更换设备时需要保留有效来源或重新选择；对外分享配置前，请检查程序与图标路径中的私人信息。

默认数据位于 `%LOCALAPPDATA%\LumaDock`，包含 `config.json`、最近备份及轮转日志。损坏配置会保留原文件并尝试恢复备份；较新配置版本会拒绝向下覆盖。软件不主动上传这些数据。

### 从旧版本升级

0.10 使用配置格式 2，可以读取并升级格式 1。首次迁移会移除旧的内置栏目及其中的归属，包括“开发工具”“办公学习”“浏览器”“游戏”“其他”等；与旧内置栏目同名的手动栏目也按此处理，应用仍在“全部”中。其他自建栏目保留，之后由你决定是否删除或改名。扫描不会重新添加这些内置栏目。

0.11.1 沿用格式 2，新增文件夹固定、完整显示器自由位置和最高 20 列设置；旧自由位置在升级时保留，再次拖动后按完整屏幕保存。需要退回 0.11.0 或更早程序时，使用升级前的配置备份，避免旧程序重新归一化新字段。

升级前建议导出配置。0.9 无法读取格式 2；需要退回旧版时，先完整退出，再使用升级前导出的配置或备份恢复，不能让旧版直接覆盖新格式。恢复备份只影响 LumaDock 的整理结果与偏好，不改变原程序和桌面文件。

## 9. 桌面图标、恢复与卸载

在 **偏好设置 → 应用整理 → Windows 桌面图标** 中主动显示或隐藏 Windows 桌面图标，操作前会确认。恢复方式为再次使用该按钮，或 **Windows 桌面右键 → 查看 → 显示桌面图标**。系统桌面进程重启后，显示状态可能恢复。

卸载顺序：

1. 如果启用了开机启动，先在 LumaDock 中关闭并确认。
2. 按需要恢复 Windows 桌面图标显示。
3. 从托盘菜单完全退出 LumaDock。
4. 删除解压的程序文件夹和自行创建的 LumaDock 快捷方式。
5. 不再需要配置时，手动删除 `%LOCALAPPDATA%\LumaDock`；保留此目录可在以后继续使用原配置。

如果程序已经移动或无法启动，可在当前用户启动文件夹中仅移除 LumaDock 自有快捷方式。不要删除其他程序的启动项。LumaDock 不替换系统桌面、不注入系统进程，也不修改系统文件。

## 10. 常见问题

| 情况 | 可以先尝试 |
| --- | --- |
| 双击无法运行或提示缺少文件 | 重新完整解压 `win-x64.zip`，确认使用 x64 Windows；不要运行源码包 |
| 应用快捷键没有反应 | 快捷键可能被占用，使用 Dock 或托盘菜单 |
| 新安装的软件没有出现 | 点击刷新；仍缺失时手动添加程序或快捷方式 |
| 添加应用后看不到 | 回到应用库的“全部”，清除搜索；添加完成后会定位结果。桌面集展示真实桌面文件，登记应用不会将它复制到桌面 |
| 桌面集没有某个文件 | 按 F5，清除搜索，检查其他分页；隐藏和系统项目不显示，只读取桌面顶层 |
| 桌面集出现两个同名项目 | 检查位置提示；用户桌面与公共桌面中不同路径的同名项目会分别保留 |
| 新建文件为什么出现在 Windows 桌面 | 桌面集展示真实目录；新建的文件夹和文本文档保存在当前用户桌面 |
| 粘贴文件夹没有成功 | 点击“打开桌面”在资源管理器中复制；桌面集当前只复制普通文件，不移动原件 |
| 找不到 Word 等新建模板 | 点击“打开桌面”访问系统菜单；桌面集当前提供新建文件夹与 `.txt` |
| 找不到回收站或此电脑 | 它们是虚拟系统图标，不属于真实桌面目录清单；使用 Windows 桌面或资源管理器 |
| 一批文件中只有部分添加成功 | 查看读取结果，确认失败文件仍存在且类型受支持；其他有效入口仍保留，重复添加不会增加同一启动身份的卡片 |
| 应用只有两排 | 增大窗口或适当减小名称字号；布局保留两行名称空间，正常窗口和默认字号优先三排 |
| 想调整主窗口大小 | 从窗口边缘或四角拉伸；右上角按钮和顶部空白处双击可最大化与还原 |
| 拖 Dock 时变成了图标排序 | 从握柄或底座空白处起拖，应用图标保留排序手势 |
| Dock 被任务栏遮住 | 按 Ctrl + Alt + Space 打开应用库，在偏好设置 → Dock 恢复位置；自由摆放允许坐标重叠，仍遵守普通窗口层级 |
| 想把 Dock 放回屏幕底部 | 双击握柄或底座空白处，或使用 Dock 菜单／偏好设置中的恢复位置 |
| 自由摆放时不自动隐藏 | 自由模式保持展开；恢复四边停靠后，原自动隐藏偏好会继续生效 |
| 旧的默认分类标签不见了 | 0.10 取消自动分类；点击“新建栏目”建立自己的栏目 |
| 删除栏目后应用去了哪里 | 回到“全部”；删除栏目不删除应用，也不取消 Dock 固定 |
| 原先同名的两张卡片只剩一张 | 若指向同一本地程序，其他入口在右键“启动方式”中；原始参数仍保留 |
| 已固定的程序或文件夹暂时不显示 | 目标可能已移走或不可读；恢复目标后刷新，原固定顺序仍保留 |
| 没有图标倒影 | 在 Dock 设置中开启“图标倒影”并提高强度；省电和高对比度会暂时关闭 |
| 想让倒影更明显、底座更透明 | 在 Dock 设置提高“倒影强度”，在材质设置降低“Dock 浓度” |
| Dock 图标偏暗或颜色太浓 | 在 Dock 设置调整“图标鲜艳度”；设为 0% 恢复原色 |
| 没有运行胶囊条、不能切换窗口 | 使用任务栏切换；后台服务、受保护或跨权限应用可能无法识别 |
| 玻璃不透明或效果较弱 | 检查省电模式、系统透明效果与高对比度；不支持时会自动回退 |
| 框内动态壁纸停在旧画面 | 开启“动态透景”，选择“清透”；关闭动态透景使用的是静态折射 |
| 希望壁纸细节更多或文字更好读 | 清透模式下调整“窗口浓度”；也可按习惯选择磨砂 |
| 图标带边框、底色或显得较小 | 可能来自原始图标资源；可右键更换图标，或恢复原图标后刷新 |
| 更换的图标没有显示 | 确认本地文件仍可读、格式受支持；必要时重新选择或恢复原图标 |
| 使用时占用偏高 | 降低流动幅度或悬停强度，或开启省电模式 |
| 字号、加粗或斜体控件没有显示 | 先关闭“跟随 Windows 图标字体” |
| 想让侧栏、栏目和应用名称一起加粗 | 在“字体与文字”关闭系统跟随后开启“加粗”；跟随状态会读取已生效的 Windows 图标字重 |
| 改了系统字体，栏目文字还没更新 | 确认系统更改已应用，保持系统跟随开启，再切回窗口或点击“刷新字体” |
| 自选文字颜色在新主题中不易看清 | 在“字体与文字 → 文字颜色”选择“自动”，或重新选色 |
| 移动程序后快捷方式失效 | 为新位置的 exe 重新创建快捷方式，并重新设置开机启动 |
| 希望报告问题 | 提供版本、系统、缩放与复现步骤；分享日志前移除私人路径和内容 |
