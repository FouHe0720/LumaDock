# LumaDock 使用指南

[返回首页](../README.md) · [下载便携版](https://github.com/FouHe0720/LumaDock/releases) · [字体与文字](SYSTEM-FONTS.md)

## 1. 运行前需要什么

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / Windows 11，x64；推荐 Windows 11 |
| 程序包 | Releases 中以 `win-x64.zip` 结尾的便携包 |
| 安装依赖 | 便携包自带 .NET Desktop Runtime，无需另装 SDK 或 IDE |
| 权限 | 普通用户权限即可；受管理设备仍受组织策略限制 |
| 其他软件 | 无需额外主题工具、字体工具、图标包或后台服务 |

当前为预发布版本。Windows 11 已有构建和交互验证；Windows 10、真实混合 DPI 双屏、独占全屏游戏和长期驻留仍需专项覆盖，详见 [验证范围](validation.md)。玻璃材质取决于系统合成、透明效果和显卡驱动，部分条件下会使用更简单的背景。

## 2. 下载、解压与第一次启动

1. 在 [Releases](https://github.com/FouHe0720/LumaDock/releases) 选择需要的版本，下载 `LumaDock-版本号-win-x64.zip`。
2. 完整解压到可写且准备长期保留的位置，保留全部文件和子目录。
3. 双击 `LumaDock.exe`，等待首次应用扫描完成。
4. 点击 Dock 左端的应用库图标，或按 **Ctrl + Alt + Space**。

不要只取出 exe，也不要直接在压缩包预览中运行。`source.zip` 和 GitHub 自动生成的源码包供开发使用；从源码构建请看 [开发文档](DEVELOPMENT.md)。

首次扫描会读取当前用户和公共的开始菜单、桌面快捷方式，以及 Windows 注册应用。Dock 会从扫描结果中固定少量应用，之后可以自行移除或调整。扫描不会修改安装目录或原快捷方式。

### 创建快捷方式

在解压目录找到 `LumaDock.exe`，使用 Windows 文件右键菜单中的“创建快捷方式”或“发送到 → 桌面快捷方式”。菜单位置会随 Windows 版本变化。

已有实例运行时再次打开，会显示同一个应用窗口。移动程序文件夹后，旧快捷方式需要重新创建。开发者还可以使用 [快捷方式脚本](DEVELOPMENT.md#创建快捷方式)。

## 3. 应用库与桌面集

| 页面 | 显示什么 | 适合做什么 |
| --- | --- | --- |
| 应用库 | 开始菜单、Windows 注册应用、桌面与手动添加的应用 | 搜索、启动、分类、固定常用软件 |
| 桌面集 | 桌面上的应用快捷方式 | 集中查看和整理桌面入口 |

同一软件可以同时出现在两页，两页共享分类和 Dock 固定状态。桌面集不显示所有类型的桌面文件，也不会代替 Windows 桌面。

### 查找、启动与手动添加

- 在搜索框输入名称或启动路径的一部分；搜索按完整输入字符串匹配，不区分大小写。
- 点击应用启动它。如果能够识别已有运行窗口，会优先请求切换到该窗口。
- 点击“添加应用”，选择 `.exe`、`.lnk`、`.url` 或 `.appref-ms`。未注册的便携软件也可通过路径添加。
- 安装新软件后，点击“刷新”，或在托盘菜单选择“重新扫描应用”。既有分组、排列和隐藏记录会保留。

受限应用、失效快捷方式或不完整的注册信息可能无法解析。可重新添加有效快捷方式；软件已卸载时，原管理记录不一定随之消失，可以自行隐藏。

### 分组与排序

1. 点击“新建分组”，输入分类名称。
2. 将应用拖到分组标签上，完成归类。
3. 在应用网格中，将应用拖到另一应用前面，调整排列。

分组是单层虚拟分类，不创建真实磁盘文件夹。当前不提供分组标签本身的拖动排序、重命名或删除。默认分类只是整理建议，不改变软件安装位置。

自动分类优先识别明确的产品名称与应用标识，不认识的应用留在“其他”。创作软件和聊天工具分别归入“创作设计”“社交通讯”。拖到分组后会记住你的选择，重新扫描不会覆盖手动分类。

同一启动目标的重复快捷方式会合并，Dock 固定顺序、自选图标和桌面关联会保留。浏览器配置、不同启动参数及卸载入口不属于普通重复项。应用库与桌面集是两个视图，同一软件同时出现在两页是正常的。

### 隐藏和恢复记录

右键应用选择“删除管理记录”，确认后从 LumaDock 隐藏，同时取消其 Dock 固定状态。这个操作不会卸载软件、删除快捷方式或移动原文件。

需要恢复时，打开“偏好设置 → 应用整理 → 已隐藏的应用”，点击“恢复全部”。当前恢复操作针对全部隐藏记录。

### 更换应用图标

在应用库、桌面集或 Dock 中右键应用，选择“更换图标…”，再选一个本地文件：

- `.ico`、`.png`、`.jpg`、`.jpeg`：使用文件中的图像。
- `.exe`、`.dll`、`.lnk`：读取程序或快捷方式提供的图标资源，不运行该程序。

同一应用在应用库和 Dock 中共用选择结果。右键“恢复原图标”可回到 Windows 提供的图标；未设置自定义图标时，恢复入口可能禁用或不显示。这个操作只保存 LumaDock 中的图标来源，不修改原程序、图片或桌面快捷方式。

一些软件原始图标自带边框、底色或较宽留白。LumaDock 保留图标本来的内容；需要另一种外观时，可以选择该软件的其他真实资源或自己的图片。自定义图标按路径读取，请将文件放在准备长期保留的位置；文件不可读时会暂用系统图标来源。仅支持本地绝对路径，不支持网页、网络共享或设备路径。

在同一路径替换图片后，点击“刷新”可重新读取。移动或更名后请重新选择；不需要自定义图标时使用“恢复原图标”。

## 4. Dock 的日常使用

| 操作 | 结果 |
| --- | --- |
| 点击应用 | 启动，或请求切换到已识别的窗口 |
| 右键应用 → 固定到 Dock | 将入口加入 Dock |
| 拖动 Dock 图标 | 按插入标记调整固定顺序，支持首位、末位及任意两个图标之间 |
| 右键 Dock 应用 → 移除 | 只取消固定，应用库记录保留 |
| 右键应用 → 更换图标… / 恢复原图标 | 调整该应用在 LumaDock 中的图标来源 |
| 将支持的程序或快捷方式拖入 Dock | 在插入标记的位置添加，原桌面文件保留 |
| 将 Dock 图标拖到 Windows 桌面 | 创建真实快捷方式；原程序、已有桌面入口与 Dock 固定状态保留 |
| 悬停 | 当前图标放大、向内侧抬起，邻近图标轻轻让位，并显示名称 |

运行小圆点来自已识别的真实窗口，后台服务或无窗口进程不一定显示。跨权限、受保护窗口和某些代理宿主应用可能无法匹配或切换；可以使用 Windows 任务栏切换。

右键 Dock 空白区域可以打开应用库、添加应用、打开偏好设置或退出。托盘菜单还提供重新扫描与重启 Dock。

### 轮廓与悬停

在“偏好设置 → Dock”选择胶囊、卵石或轨道。胶囊圆润，卵石使用交错圆角，轨道更利落。轮廓随停靠方向调整，放大图标保留独立空间。

“悬停放大强度”调节图标放大与抬起幅度。设为 0% 或关闭界面动画可停止这组动效；省电模式也会减少动态效果。图标停稳后不持续播放动画。

### 位置、自动隐藏与双屏

在“偏好设置 → Dock”中选择顶部、底部、左侧或右侧。Dock 按显示器工作区定位，避开通常的任务栏区域。

开启“自动隐藏”后，鼠标离开会短暂延迟收起；移到所选屏幕相应的工作区边缘，可重新显示。前台窗口覆盖所选屏幕时会尝试隐藏 Dock，特殊全屏和独占游戏仍可能需要单独调整。

双屏使用时，在“显示器”下拉中选择目标屏幕；“主显示器（自动）”使用系统当前主屏。断开所选屏幕后会回退主屏。每块屏幕的缩放由 Windows 与 WPF 处理，若更改缩放后位置异常，可用托盘菜单“重启 Dock”重新定位。

## 5. 颜色与玻璃

打开“偏好设置”，点击顶部“材质”。

| 设置 | 用途 |
| --- | --- |
| 强调色 | 潮蓝、青瓷、琥珀、烟紫、玫瑰、石墨，用于按钮、选中状态与边缘反光 |
| 主题 | 跟随系统、深色或浅色 |
| 液态玻璃 | 控制自定义透景、静态折射与相关流光；关闭后管理窗口保留系统支持的背景 |
| 动态透景 | 默认开启；后方画面交给系统合成，不叠加低频背景快照 |
| 透景风格 | 动态模式下选择清透或磨砂，默认清透；清透保留壁纸细节，磨砂柔化后方画面 |
| 窗口浓度 | 清透模式下显示，25–90%，默认 65%；调节管理窗口的底色浓度，不改变 Dock 透明度 |
| 玻璃流动 | 指针移动时短暂的边缘反光，停下后收住 |
| 流动幅度 | 反光强度，设为 0% 可停止流光 |
| 静态折射清晰度 | 关闭动态透景后显示；低值更柔和，高值保留更多后方细节 |
| Dock 透明度、轮廓、圆角、图标大小与间距 | 调整 Dock 外形和密度；轮廓决定圆角的整体比例 |

### 动态与静态怎么选

使用动态壁纸时，保持“动态透景”开启，并选择“清透”。管理窗口会保留后方画面细节，Dock 使用真实透明底座；两者都由系统合成，不叠加低频背景快照。

清透模式的“窗口浓度”默认 65%。需要更多壁纸细节时降低浓度，需要更安静的阅读背景时提高浓度；如果偏爱柔和的背景，可手动选择“磨砂”。窗口浓度用于管理窗口，Dock 的透明度由单独的选项调节。

动态模式保留矢量边缘与流光，不执行实时曲边像素折射，也不承诺固定帧率或零延迟。当前清透路径在 Windows 11 验证环境下测试；Windows 10 仍待专项验证。系统透明效果关闭、高对比度、节电或不支持合成时使用不透明回退，应用不会替用户更改这些系统设置。

关闭“动态透景”后使用静态折射。打开、移动、调整窗口尺寸或相关背景事件会更新一次背景，平时保留该画面；动画壁纸在框内不会持续跟随。这时可调整“静态折射清晰度”。

流光、图标放大和背景模式可以分别选择。希望进一步减少材质与动效时，可开启“省电模式”。图标停稳后结束动画，空闲 Dock 不持续播放流光。

静态折射的背景像素只在本地内存中处理，普通运行不写入背景截图，也不上传。其短暂采样排除可能使同时运行的录屏或截图程序漏掉 LumaDock；默认动态透景不使用这条应用采样路径。开发诊断模式可能另存渲染图，分享前需要检查内容。

## 6. 字体与文字

1. 打开“偏好设置”，点击顶部“文字”，定位到“字体与文字”。
2. 关闭“跟随 Windows 图标字体”。
3. 选择已安装字体，调整名称字号、加粗或斜体。
4. 查看下方“文字预览”，松开滑块或结束键盘操作后自动保存。

字体、粗细和斜体同时用于侧栏、分类、标题、搜索与设置文字，以及应用名称和 Dock 名称提示。名称字号范围为 **7.5–30 磅**；大字号会自动减少列数，并为两行名称留出空间。标题、导航和说明保留各自的字号，避免侧栏被放大挤满；标题与选中标签至少保持半粗。

“文字颜色”可选自动配色或五种预设；“自选颜色…”支持 `#RRGGBB`，例如 `#D7ECF4`，留空恢复自动。颜色用于主要标签和应用名称，说明、计数及强调色按钮保留各自的配色。自选颜色在主题切换时保留，若与背景接近，可改回“自动”；高对比度模式优先使用 Windows 文字颜色。

这些控件只调整 LumaDock。若希望沿用 Windows 当前图标标题字体，保持“跟随 Windows 图标字体”开启；字体或粗细在系统中实际生效后切回 LumaDock，必要时点击“系统图标字体 → 刷新字体”。跟随系统时也能单独选择文字颜色。详细范围见 [字体与文字说明](SYSTEM-FONTS.md)。

## 7. 开机启动、关闭与退出

在“偏好设置 → 性能与启动”中启用“随 Windows 启动”，确认后会在当前用户的启动文件夹创建 LumaDock 自有快捷方式。此项默认关闭，不写系统 Run 注册表。

请先将程序放在长期保留的位置，再启用开机启动。移动文件夹前先关闭此项，移动后重新开启。Windows 启动管理或组织策略仍可能禁用入口。

默认关闭管理窗口后继续驻留托盘。完全结束请使用托盘或 Dock 菜单的“退出 LumaDock”。关闭“关闭窗口后驻留托盘”后，关闭窗口也会退出程序。

## 8. 配置备份与恢复

“偏好设置 → 数据”提供：

- **导出配置**：保存分组、排列、固定状态、外观与自定义图标路径的 JSON 备份。
- **导入配置**：确认后替换整理结果与偏好，建议先导出当前配置。
- **恢复默认值**：重置 LumaDock 整理与偏好，不移动原文件。

导入与重置不会自动启用开机启动，也不会改变 Windows 桌面图标显示。配置中的程序路径只对仍存在的应用有效；导入另一台设备时，可能需要重新添加路径。

配置导出记录图标文件路径，不复制图标文件。更换设备时需要保留有效来源或重新选择；对外分享配置前，请检查程序与图标路径中的私人信息。

默认数据位于 `%LOCALAPPDATA%\LumaDock`，包含 `config.json`、最近备份及轮转日志。损坏配置会保留原文件并尝试恢复备份；较新配置版本会拒绝向下覆盖。软件不主动上传这些数据。

## 9. 桌面图标、恢复与卸载

桌面集的“桌面图标”按钮用于主动显示或隐藏 Windows 桌面图标，操作前会确认。恢复方式为再次使用该按钮，或 **Windows 桌面右键 → 查看 → 显示桌面图标**。系统桌面进程重启后，显示状态可能恢复。

卸载顺序：

1. 如果启用了开机启动，先在 LumaDock 中关闭并确认。
2. 按需要恢复 Windows 桌面图标显示。
3. 从托盘菜单完全退出 LumaDock。
4. 删除解压的程序文件夹和自行创建的 LumaDock 快捷方式。
5. 不再需要配置时，手动删除 `%LOCALAPPDATA%\LumaDock`；保留此目录可在以后继续使用原配置。

如果程序已经移动或无法启动，可在当前用户启动文件夹中仅移除 LumaDock 自有快捷方式。不要删除其他程序的启动项。LumaDock 不替换系统桌面、不注入系统进程，也不修改系统文件。

## 10. 常见问题

| 情况 | 可以先尝试 |
| --- | --- |
| 双击无法运行或提示缺少文件 | 重新完整解压 `win-x64.zip`，确认使用 x64 Windows；不要运行源码包 |
| 应用库快捷键没有反应 | 快捷键可能被占用，使用 Dock 或托盘菜单 |
| 新安装的软件没有出现 | 点击刷新；仍缺失时手动添加程序或快捷方式 |
| 没有运行小圆点、不能切换窗口 | 使用任务栏切换；受保护或跨权限应用可能无法识别 |
| 玻璃不透明或效果较弱 | 检查省电模式、系统透明效果与高对比度；不支持时会自动回退 |
| 框内动态壁纸停在旧画面 | 开启“动态透景”，选择“清透”；关闭动态透景使用的是静态折射 |
| 希望壁纸细节更多或文字更好读 | 清透模式下调整“窗口浓度”；也可按习惯选择磨砂 |
| 图标带边框、底色或显得较小 | 可能来自原始图标资源；可右键更换图标，或恢复原图标后刷新 |
| 更换的图标没有显示 | 确认本地文件仍可读、格式受支持；必要时重新选择或恢复原图标 |
| 使用时占用偏高 | 降低流动幅度或悬停强度，或开启省电模式 |
| 字号、加粗或斜体控件没有显示 | 先关闭“跟随 Windows 图标字体” |
| 想让侧栏、分类和应用名称一起加粗 | 在“字体与文字”关闭系统跟随后开启“加粗”；跟随状态会读取已生效的 Windows 图标字重 |
| 改了系统字体，栏目文字还没更新 | 确认系统更改已应用，保持系统跟随开启，再切回窗口或点击“刷新字体” |
| 自选文字颜色在新主题中不易看清 | 在“字体与文字 → 文字颜色”选择“自动”，或重新选色 |
| 移动程序后快捷方式失效 | 为新位置的 exe 重新创建快捷方式，并重新设置开机启动 |
| 希望报告问题 | 提供版本、系统、缩放与复现步骤；分享日志前移除私人路径和内容 |
