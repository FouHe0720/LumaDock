# LumaDock 0.11.3

**小得下，也拿得稳。**

[使用指南](USER-GUIDE.md) · [验证范围](validation.md) · [性能记录](performance.md)

## 收小，仍然清楚

图标最小尺寸降至 **16 DIP**，可直接拉动缩放，也可在 **偏好设置 → Dock → 图标大小** 调整。尺寸范围为 **16–160 DIP**，原有偏好保留，不自动改成最小值。

小图标搭配更薄的底座：16 DIP 图标对应约 32 DIP 厚的玻璃底座，L 图标也一起收小。常用尺寸继续保留原来的比例。实际像素尺寸随 Windows 显示缩放变化。

## 两端，留出好抓的空位

底座两端各保留 **32 DIP 空位**，将操作握柄与应用分开。横向 Dock 的左端负责移动、右端负责缩放；竖向摆放时分别位于上端和下端。

握柄的可抓取区域沿底座方向加宽到 **24 DIP**，小尺寸下也容易抓住。悬停或滚动时，握柄区域优先响应移动和缩放，减少误点应用；应用图标本身继续负责启动、排序与固定。

## 减少拖动中的重复工作

手势开始时取得显示器信息，预览复用这份快照；坐标与 DPI 都未变化时跳过重复布局。图标、控件和已加载图像继续复用，预览更新合并到渲染队列，松手后才保存一次并更新清晰图标。

按 **Esc**、失去鼠标捕获或屏幕布局改变时取消本次预览。没有新增常驻鼠标轮询，也不靠持续动画维持静置效果。资源实测按最终程序单独记录，不用历史数据推算提速比例。

## 原来的习惯，继续使用

自由摆放、任务栏区域落点、重启恢复、悬停与倒影、应用库、真实桌面集、最高 20 列和文件夹固定继续保留。Dock 保持普通窗口层级，工作窗口仍在上方；Windows 任务栏可能遮住重叠部分。

需要恢复位置时，按 **Ctrl + Alt + Space** 打开应用库，再进入 **偏好设置 → Dock → 恢复位置**。

下载 **LumaDock-0.11.3-win-x64.zip**，完整解压后双击 **LumaDock.exe**。便携包自带 .NET Desktop Runtime，无需另装 SDK 或 IDE。更新前可导出配置备份，退出旧进程后替换程序文件，原有数据目录保留。

## 本版验证

Windows Release 构建、自包含发布、281 项定向组件与 WPF 检查通过。实际鼠标验证了 16 DIP 下的握柄移动、放大与缩回最小值。实测小尺寸与常规 Dock 私有工作集峰值分别为 47.7 MB、48.8 MB，平均全机 CPU 为 0.00880%、0.02078%；各预热 20 秒后请求采样 30 秒，固定 2 个程序和 1 个测试文件夹、倒影 90%。这是短时静置采样，不代表持续拖动、GPU 或长期驻留。
